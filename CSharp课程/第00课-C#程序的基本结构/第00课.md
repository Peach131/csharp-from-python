# 第 00 课 ｜ C# 程序的基本结构

> **本课目标**：看懂一个 C# 程序是由哪几块组成的，并且能自己写出一个能运行的程序。
> **预计时间**：40-60 分钟
> **前置要求**：无。这是第一课。
> **本课涉及的语法**：`using`、`namespace`、`class`、`static`、`void`、`Main` 方法、`Console.WriteLine`、`字符串插值 $""`、注释

## 一、先看一个最小的 C# 程序

```csharp
using System;

namespace MyFirstApp
{
    class Program
    {
        static void Main()
        {
            Console.WriteLine("你好，C#");
        }
    }
}
```

**这 11 行代码，每一行都有存在的理由。** 下面逐块拆开讲。

> 💡 **Python 对照**：Python 里写 `print("你好")` 一行就能跑。
> C# 要写 11 行——这是你第一个会感到"啰嗦"的地方。
> **为什么必须这样？** 因为 C# 需要**明确的类型和结构**才能编译。
> 代价是啰嗦，收益是：编译器能提前发现错误，IDE 能精确补全和重构。

## 二、逐块讲解：每一部分是干什么的

### 第 1 块：`using System;` —— 引用别人写好的代码

```csharp
using System;
```

- **`using`** 的意思是"我接下来要用到这个命名空间里的东西"。
- **`System`** 是 .NET 自带的一个命名空间，里面装着最基础的类型：`Console`、`String`、`Math`、`DateTime` 等等。
- 因为这一行，你下面才能直接写 `Console.WriteLine`。如果没有这一行，就得写全名 `System.Console.WriteLine`。

**Python 对照**：
```python
import sys        # Python 的 import
using System;     // C# 的 using
```
几乎是一样的概念。区别是：Python 的 `import` 后面跟的是**模块**，C# 的 `using` 后面跟的是**命名空间**。

**易错点**：你还没用到的命名空间不要写。写了会有黄色警告（提示"这个 using 没用"）。

---

### 第 2 块：`namespace MyFirstApp { ... }` —— 给代码分组的文件夹

```csharp
namespace MyFirstApp
{
    // 这里面放你的代码
}
```

- **`namespace`** 叫"命名空间"，作用是**给代码分组，避免重名冲突**。
- 花括号 `{ }` **里面**的所有东西，都属于 `MyFirstApp` 这个组。
- `MyFirstApp` 这个名字是**你自己起的**，通常和项目名一致。

**为什么需要它？**
假设你写了一个 `Logger` 类，别人也写了一个 `Logger` 类。如果没有命名空间，它们会冲突。
有了命名空间，就是 `我的项目.Logger` 和 `别人的项目.Logger`，两个并存没问题。

**Python 对照**：Python 用**文件名**当模块名（`utils.py` → `utils`）。
C# 用**命名空间**，而且它是显式声明的，不是靠文件名。

**易错点**：
- 命名空间名字后面**没有分号**
- `{` 和 `}` 必须配对，初学者最常犯的错就是少一个大括号

---

### 第 3 块：`class Program { ... }` —— C# 里所有代码都必须待在类里面

```csharp
class Program
{
    // 这里面放你的方法
}
```

- **`class`** 是"类"，你可以先把它理解成**一个装着代码的盒子**。
- **`Program`** 是这个类的名字。惯例是**首字母大写**。
- **C# 的硬性规定：所有代码都必须写在某个类里面。** 你不能像 Python 那样在文件顶层直接写语句。

**Python 对照**：
```python
# Python：可以直接在文件顶层写代码
print("hello")

def my_func():
    print("hi")
```
```csharp
// C#：必须先有一个 class，再把代码放进去
class Program
{
    static void Main()
    {
        Console.WriteLine("hello");
    }
}
```

> ⚠️ **这条规则你现在必须记住**：C# 里不存在"文件顶层的语句"。
> 一切都要放进 `class` 里。（例外：C# 9 之后有"顶级语句"语法糖，但那是编译器帮你偷偷生成类，本质不变。我们先用完整写法，把结构看清楚。）

---

### 第 4 块：`static void Main()` —— 程序的入口

```csharp
static void Main()
{
    // 程序从这里开始执行
}
```

这一行有 4 个词，每个都有用：

| 词 | 含义 | 现在你只需要知道 |
|---|---|---|
| `static` | 静态的 | 表示"这个方法不用创建对象就能调用"。**先照抄，第 5 课会讲** |
| `void` | 空的 | 表示"这个方法**不返回任何值**"。如果返回整数就写 `int` |
| `Main` | 方法名 | **必须是 `Main`**，这是 C# 规定的程序入口 |
| `()` | 参数列表 | 括号里是参数。空的表示"不需要参数" |

**关键点：程序永远从 `Main` 方法的第一行开始执行。**

**Python 对照**：
```python
if __name__ == "__main__":     # Python 的入口约定
    main()
```
Python 的入口是**约定**（靠 `if __name__` 判断）；C# 的 `Main` 是**规定**——运行时直接找名叫 `Main` 的方法。

**易错点**：
- 名字必须是 `Main`（大写 M）。写成 `main` 会报错"找不到入口点"。
- `Main` 必须是 `static`。漏了会报错。

---

### 第 5 块：`Console.WriteLine("你好，C#");` —— 往屏幕打印

```csharp
Console.WriteLine("你好，C#");
```

- **`Console`** 是 .NET 提供的一个类，代表控制台窗口。
- **`WriteLine`** 是它的一个方法，作用是"打印一行并换行"。
- **`("...")`** 括号里是要打印的内容，用**双引号**包起来。
- **分号 `;`** 表示这句结束。**C# 每条语句末尾都要有分号**（这是和 Python 最大的视觉差异）。

**和 `Write` 的区别**：
```csharp
Console.WriteLine("A");   // 打印 A 然后换行
Console.Write("A");       // 打印 A，不换行
```

**Python 对照**：`Console.WriteLine(x)` ≈ `print(x)`

**易错点**：
- 忘记分号 → 报错 `; expected`
- 用了中文引号 `“”` 而不是英文引号 `""` → 报错，而且很难看出来
- 忘记 `using System;` → 报错"找不到 Console"

---

### 第 6 块：注释 —— 给自己看的说明

```csharp
// 这是单行注释，从 // 到行尾都会被忽略

/*
   这是多行注释
   可以写好几行
*/

/// <summary>
/// 这是文档注释，会显示在 IDE 的提示里
/// </summary>
```

**Python 对照**：
```python
# 这是单行注释      ← 和 C# 的 // 作用一样，符号不同
"""这是文档字符串"""  ← 对应 C# 的 /// <summary>
```

**快捷键**：选中代码按 **`Ctrl + /`** 可以注释/取消注释。

## 三、本课新语法速查表

| 语法 | 作用 | Python 对照 | 注意 |
|---|---|---|---|
| `using System;` | 引用命名空间 | `import sys` | 末尾有分号 |
| `namespace X { }` | 给代码分组 | 文件名即模块 | 名字后无分号 |
| `class X { }` | 装代码的盒子 | `class X:` | C# 所有代码必须在类里 |
| `static void Main()` | 程序入口 | `if __name__ == "__main__"` | 必须是 `Main`，大写 M |
| `Console.WriteLine(x)` | 打印一行 | `print(x)` | 注意分号 |
| `;` | 语句结束 | 换行即结束 | **最容易漏** |
| `{ }` | 代码块 | 缩进 | **最容易不配对** |
| `//` | 单行注释 | `#` | `Ctrl + /` |
| `$"文本 {变量}"` | 字符串插值 | `f"文本 {变量}"` | 见下文第 5 节 |

## 五、看懂这段代码所需的额外语法：`$""` 字符串插值

你在示例里会看到这种写法：

```csharp
int age = 25;
Console.WriteLine($"我今年 {age} 岁");
```

- 字符串前面加一个 **`$`**，表示"这个字符串里有变量要替换"
- 字符串里用 **`{ }`** 把变量名包起来，运行时会被替换成变量的值
- **和 Python 的 f-string 完全一样**

```python
age = 25
print(f"我今年 {age} 岁")      # Python
```
```csharp
int age = 25;
Console.WriteLine($"我今年 {age} 岁");   // C#
```

> ⚠️ 注意 C# 的 `$` 在**引号外面**（`$"..."`），Python 的 `f` 也在引号外面（`f"..."`）。
> 位置一样，符号不同。

## 八、本课的"坑"预告

初学 C# 最常犯的 5 个错误，你一定会遇到至少 3 个：

| 错误 | 报错信息 | 原因 |
|---|---|---|
| 忘记分号 | `; expected` | C# 每条语句必须 `;` 结尾 |
| 大括号不配对 | `} expected` | `{` 和 `}` 数量必须相等 |
| 用了中文引号 | `Character constant too long` 之类 | 必须是英文 `"`，不是中文 `“”` |
| 忘记 `using System;` | `找不到 Console` | 没引用命名空间 |
| `Main` 写成 `main` | `找不到适合的入口点` | C# 区分大小写，必须 `Main` |

> **C# 严格区分大小写**（Python 也是），但 C# 的惯例更严格：
> 类名和方法名用**大写开头**（`Program`、`WriteLine`），
> 局部变量用小写开头（`age`、`userName`）。这个惯例叫 PascalCase / camelCase，
> 第 5 课会专门讲。
