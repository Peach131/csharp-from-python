## 一、为什么需要循环

没有循环，你要这样算 1 加到 5：

```csharp
int sum = 1 + 2 + 3 + 4 + 5;      // 累死了
```

要算 1 加到 1000 呢？**循环就是"让计算机重复做同一件事"。**

## 二、`for` 循环 —— 最常用

### 语法结构

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
// 输出：0 1 2 3 4
```

**把它拆开看，`for` 的括号里有三段，用两个分号隔开**：

```
for ( ①  int i = 0  ;  ②  i < 5  ;  ③  i++  )
     └────┬────┘      └───┬───┘      └─┬─┘
      初始化            循环条件      每次循环后执行
      只执行一次        为 true 才继续
```

**执行顺序（这个必须搞清楚）**：

```
    ① 初始化：i = 0
         ↓
    ② 判断 i < 5  →  true
         ↓
    执行 { } 里的代码
         ↓
    ③ i++  →  i = 1
         ↓
    ② 判断 i < 5  →  true
         ↓
    执行 { } 里的代码
         ↓
    ③ i++  →  i = 2
         ↓
       ... 重复 ...
         ↓
    ② 判断 i < 5  →  false   ← i 变成 5 了
         ↓
      循环结束
```

> **⚠️ 最容易搞错的一点**：`③ i++` 是在**每次循环体执行完之后**才执行的，
> 不是在每次循环开始前。
>
> 所以 `for (int i = 0; i < 5; i++)` 循环体的 `i` 依次是 **0, 1, 2, 3, 4**（共 5 次），
> **不是 0, 1, 2, 3, 4, 5**。

### Python 对照

```python
# Python
for i in range(5):
    print(i)
```
```csharp
// C#
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
```

**Python 的 `range(5)` 帮你隐藏了三个部分，C# 要你全部写出来。**

对照表：

| Python | C# |
|---|---|
| `for i in range(5)` | `for (int i = 0; i < 5; i++)` |
| `for i in range(1, 6)` | `for (int i = 1; i <= 5; i++)` |
| `for i in range(0, 10, 2)` | `for (int i = 0; i < 10; i += 2)` |
| `for i in range(10, 0, -1)` | `for (int i = 10; i > 0; i--)` |

### ⚠️ 陷阱：差一错误（off-by-one）

初学者最常犯的错：**到底用 `<` 还是 `<=`？**

```csharp
// 遍历 5 个元素（索引 0~4）
int[] arr = new int[5];
for (int i = 0; i < arr.Length; i++)      // ✅ 用 <（因为索引从 0 开始）
{
    Console.WriteLine(arr[i]);
}

// ❌ 用 <= 会越界！
// for (int i = 0; i <= arr.Length; i++)  // i 会到 5，但最大索引是 4 → 崩溃
```

**规则记牢**：

> **数组索引从 0 开始，最后一个索引是 `Length - 1`。**
> **所以遍历用 `i < arr.Length`，不要用 `<=`。**

**越界的后果**（实测）：

```
IndexOutOfRangeException: Index was outside the bounds of the array.
```

## 三、`while` 循环 —— 不知道要循环几次时用

```csharp
int i = 0;
while (i < 5)
{
    Console.WriteLine(i);
    i++;                     // ⚠️ 一定要记得改变条件，否则死循环！
}
```

**`for` 和 `while` 的关系**：

```csharp
// 这两种写法完全等价
for (int i = 0; i < 5; i++) { Console.WriteLine(i); }

int i = 0;
while (i < 5) { Console.WriteLine(i); i++; }
```

**什么时候用哪个？**

| 用 `for` | 用 `while` |
|---|---|
| **知道循环几次**（或有一个明确的计数器） | **不知道几次**，只知道"条件满足就继续" |
| 遍历数组、循环 N 次 | 读用户输入直到输入 `quit`、猜数字游戏 |

**`while` 的典型用法**：

```csharp
// 让用户一直输入，直到输入 "quit"
string? input;
while ((input = Console.ReadLine()) != "quit")
{
    Console.WriteLine($"你输入了：{input}");
}
```

### ⚠️ 死循环

```csharp
int i = 0;
while (i < 5)
{
    Console.WriteLine(i);
    // 忘了 i++  →  永远打印 0，程序卡死
}
```

**如果真卡死了怎么办**：在 Rider 里按 **`Ctrl + F2`** 强制停止。
（或者关掉控制台窗口。）

## 四、`do-while` —— 至少执行一次

```csharp
int dw = 10;
do
{
    Console.WriteLine("do-while 执行了");
    dw++;
} while (dw < 5);            // ← 注意结尾有【分号】！
```

**实测结果**：条件 `10 < 5` 是 false，但**还是执行了一次**。

| | `while` | `do-while` |
|---|---|---|
| 先判断还是先执行 | **先判断**，再执行 | **先执行**，再判断 |
| 最少执行次数 | **0 次** | **1 次** |
| 结尾分号 | 没有 | **有** `} while (...);` |

**什么时候用 `do-while`？** 当"至少要执行一次"时，比如：

```csharp
// 菜单：至少显示一次，然后问用户要不要继续
string? again;
do
{
    Console.WriteLine("执行菜单操作...");
    Console.Write("要继续吗？(y/n)：");
    again = Console.ReadLine();
} while (again == "y");
```

> **Python 没有 `do-while`**。Python 里要写 `while True:` + `break` 才能模拟。

## 五、`foreach` —— 遍历集合最简洁

```csharp
int[] nums = { 10, 20, 30 };

foreach (int n in nums)
{
    Console.WriteLine(n);
}
// 输出：10 20 30
```

**语法结构**：

```
foreach ( 类型 变量名 in 集合 )
         └──┬──┘  └─┬─┘    └─┬─┘
        每个元素  ← 临时变量  要遍历的东西
        的类型    每次装一个元素
```

**Python 对照**：**这个和 Python 的 `for` 几乎完全一样！**

```python
# Python
for n in nums:
    print(n)
```
```csharp
// C#
foreach (int n in nums)
{
    Console.WriteLine(n);
}
```

> **注意区分**：C# 的 `foreach` 对应 Python 的 `for x in list`；
> C# 的 `for` 对应 Python 的 `for i in range(...)`。**名字一样，含义不同。**

### ⚠️⚠️ 关键陷阱：`foreach` 里**不能修改**元素

```csharp
int[] nums = { 1, 2, 3 };

// ❌ 编译错误
foreach (int n in nums)
{
    // n = 99;              // 无法为"n"赋值，因为它是 foreach 迭代变量
}
```

**为什么？** `foreach` 里的 `n` 只是元素的**副本**（对于值类型）或**只读引用**，
它不是一个"可以修改的东西"。

**想修改元素，必须用 `for` + 索引**（实测）：

```csharp
int[] nums = { 1, 2, 3 };

for (int i = 0; i < nums.Length; i++)
{
    nums[i] *= 10;          // ✅ 通过索引可以直接改数组里的元素
}
Console.WriteLine(string.Join(", ", nums));   // 10, 20, 30
```

**怎么选？**

| 场景 | 用哪个 |
|---|---|
| 只**读**元素，不需要索引 | `foreach`（更简洁，不容易越界） |
| 需要**修改**元素 | `for` + 索引 |
| 需要知道**索引值** | `for` + 索引 |

> **Python 对照**：Python 的 `for n in nums:` 里改 `n` 也**不会**影响原列表，
> 这点两个语言一致。但 Python 的 `for i in range(len(nums))` 里改 `nums[i]` 是可以的，
> 和 C# 的 `for` 一样。

## 六、`break` 和 `continue`

| 关键字 | 作用 | 记忆 |
|---|---|---|
| `break` | **立刻跳出整个循环** | "不干了，走人" |
| `continue` | **跳过本次，进入下一次循环** | "这次算了，下一个" |

**实测输出**：

```csharp
// break：遇到 3 就整个停下
for (int i = 1; i <= 6; i++)
{
    if (i == 3) break;
    Console.Write(i + " ");
}
// 输出：1 2

// continue：跳过 3，继续后面的
for (int i = 1; i <= 6; i++)
{
    if (i == 3) continue;
    Console.Write(i + " ");
}
// 输出：1 2 4 5 6
```

**图示对比**：

```
数组:  [1] [2] [3] [4] [5] [6]

break 遇到 3:      1  2  ✂️(停)
continue 遇到 3:   1  2  ⏭️  4  5  6
```

**`break` 的实用场景**：在一堆数据里找到目标就停止（不用白跑剩下的）：

```csharp
int[] data = { 5, 12, 8, 99, 3 };
int target = 8;
int foundIndex = -1;

for (int i = 0; i < data.Length; i++)
{
    if (data[i] == target)
    {
        foundIndex = i;
        break;                    // 找到了就停，不用继续找
    }
}
Console.WriteLine(foundIndex >= 0 ? $"在索引 {foundIndex} 找到" : "没找到");
```

## 七、数组

### 声明和初始化（4 种写法）

```csharp
// ① 声明时直接给初值（最常用）
int[] nums = { 1, 2, 3, 4, 5 };

// ② 指定长度，元素自动填默认值（int 默认 0）
int[] zeros = new int[5];              // { 0, 0, 0, 0, 0 }

// ③ 显式写类型 + 长度 + 初值
int[] explicit1 = new int[3] { 10, 20, 30 };

// ④ 用 var
var varArr = new[] { 1, 2, 3 };        // 编译器推断成 int[]
```

**语法拆解**：

```
int[] nums = { 1, 2, 3 };
 │ │   │
 │ │   └── 大括号里是【元素】，用逗号分隔
 │ └────── 变量名
 └──────── int[] 表示"int 的数组"（注意是 [] 方括号）

int[] zeros = new int[5];
                  │   │  └── 长度 5
                  │   └───── 元素类型
                  └───────── new 表示"创建新数组"
```

### ⚠️ 数组最重要的特性：**长度固定，不能改变**

```csharp
int[] nums = new int[3];
nums[0] = 10;
nums[1] = 20;
nums[2] = 30;
// nums[3] = 40;          // ❌ IndexOutOfRangeException，数组只有 3 个位置

// 数组创建后【不能】变大。想加第 4 个元素？只能新建一个更大的数组。
```

> **Python 对照**：Python 的 `list` 可以随便 `append`。
> **C# 的数组不行！** 需要可变长度的用 `List<int>`（第 09 课会讲）。
>
> **这是 Python 转 C# 必须记住的一条**：`int[]` ≠ Python `list`。
> C# 的 `int[]` 更像 Python 的 `array` 或者"固定长度的 list"。

### 数组的常用属性

```csharp
int[] nums = { 5, 2, 8, 1 };

nums.Length              // 4          元素个数（注意是 Length，不是 Count）
nums[0]                  // 5          第一个（索引从 0 开始）
nums[nums.Length - 1]    // 1          最后一个
nums[^1]                 // 1          C# 8+ 的新写法：^1 表示"倒数第一个"
nums[^2]                 // 8          倒数第二个

Array.Sort(nums);        // 原地排序 → { 1, 2, 5, 8 }
Array.Reverse(nums);     // 原地反转
Array.IndexOf(nums, 8)   // 查找元素位置，找不到返回 -1
Array.Clear(nums);       // 全部清成默认值
```

### ⚠️ `Length` 还是 `Count`？

**这是初学者最常搞混的一对**：

| 类型 | 用哪个 | 实测 |
|---|---|---|
| **数组** `int[]` | **`.Length`** | `new int[5].Length` = 5 |
| **字符串** `string` | **`.Length`** | `"hello".Length` = 5 |
| **`List<T>`** | **`.Count`** | `new List<int>{1,2,3}.Count` = 3 |

> **记法**：**数组和字符串用 `Length`（长度），List 用 `Count`（数量）。**
> 用错了 IDE 会报错提示，但你要知道该用哪个。

### 把数组变成字符串：`string.Join`

```csharp
int[] nums = { 1, 2, 3 };
Console.WriteLine(string.Join(", ", nums));      // 1, 2, 3
Console.WriteLine(string.Join(" | ", nums));     // 1 | 2 | 3
```

**Python 对照**：`", ".join(nums)` → C# 是 `string.Join(", ", nums)`。
注意参数顺序反过来了！Python 是"分隔符.join(数组)"，C# 是"Join(分隔符, 数组)"。

## 八、嵌套循环

循环里面套循环：

```csharp
// 打印一个 3 行的三角形
for (int i = 1; i <= 3; i++)              // 外层：控制"第几行"
{
    for (int j = 1; j <= i; j++)          // 内层：控制"这一行打印几个"
    {
        Console.Write("*");
    }
    Console.WriteLine();                   // 一行结束后换行
}
```

**输出**：
```
*
**
***
```

**执行过程追踪**（这个必须看懂）：

| 外层 i | 内层 j 的取值 | 输出 |
|---|---|---|
| 1 | 1 | `*` 然后换行 |
| 2 | 1, 2 | `**` 然后换行 |
| 3 | 1, 2, 3 | `***` 然后换行 |

> **关键理解**：外层每走 **1 步**，内层就要完整走 **一整轮**。
> 所以 3 行三角形的总循环次数 = 1 + 2 + 3 = 6 次。

**经典应用**：九九乘法表

```csharp
for (int i = 1; i <= 9; i++)
{
    for (int j = 1; j <= i; j++)
    {
        Console.Write($"{j}×{i}={i * j}\t");    // \t 是制表符，用来对齐
    }
    Console.WriteLine();
}
```

## 九、二维数组（矩形数组）—— 了解即可

```csharp
int[,] grid = new int[2, 3]
{
    { 1, 2, 3 },         // 第 0 行
    { 4, 5, 6 }          // 第 1 行
};
```

**注意方括号里是逗号**：`int[,]` 表示二维，`int[,,]` 表示三维。

**访问和遍历**：

```csharp
Console.WriteLine(grid[1, 2]);           // 6      第1行第2列
Console.WriteLine(grid.GetLength(0));    // 2      行数
Console.WriteLine(grid.GetLength(1));    // 3      列数
Console.WriteLine(grid.Length);          // 6      总元素数

// 遍历用嵌套循环
for (int row = 0; row < grid.GetLength(0); row++)
{
    for (int col = 0; col < grid.GetLength(1); col++)
    {
        Console.Write($"{grid[row, col]}\t");
    }
    Console.WriteLine();
}
```

> **⚠️ 注意**：二维数组用 **`GetLength(维度)`**，不是 `Length`（`Length` 是总元素数）。
> 这一点和 Python 的 `numpy` 有点像，但语法不同。
>
> **本课只需要"看得懂"**，实际项目里二维数组用得不多（多用 `List<List<int>>` 或自定义类）。

## 十、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `for (int i = 0; i < n; i++)` | 计数循环 | `for i in range(n)` | 三段用 `;` 分隔 |
| `while (条件)` | 条件循环 | `while 条件:` | **别忘了改变条件，否则死循环** |
| `do { } while (条件);` | 至少执行一次 | 无 | **结尾有分号** |
| `foreach (int x in arr)` | 遍历集合 | `for x in arr:` | **不能修改元素** |
| `break` | 跳出整个循环 | `break` | — |
| `continue` | 跳过本次 | `continue` | — |
| `int[] a = { 1, 2, 3 };` | 声明并初始化数组 | `a = [1,2,3]` | **长度固定！** |
| `new int[5]` | 创建长度 5 的数组 | `[0]*5` | 元素自动填默认值 0 |
| `arr.Length` | 元素个数 | `len(arr)` | **数组用 Length** |
| `list.Count` | 元素个数 | `len(list)` | **List 用 Count** |
| `arr[^1]` | 最后一个元素 | `arr[-1]` | C# 8+ 语法 |
| `string.Join(", ", arr)` | 数组转字符串 | `", ".join(arr)` | **参数顺序相反** |
| `Array.Sort(arr)` | 原地排序 | `arr.sort()` | 改变原数组 |
| `int[,]` | 二维数组 | 嵌套 list | 用 `GetLength(n)` |
