## 一、先解决一个悬了很久的问题：`static` 是什么

你从第 00 课开始就一直在写：

```csharp
static void Main() { }
static int Add(int a, int b) { }
```

**现在正式回答：`static` 表示"属于类本身，不属于某个具体对象"。**

### 对比：实例成员 vs 静态成员

```csharp
class Counter
{
    public int InstanceCount = 0;            // 实例字段：每个对象各有一份
    public static int TotalCount = 0;        // 静态字段：所有对象共享一份
}
```

```csharp
var a = new Counter();
var b = new Counter();

a.InstanceCount = 10;        // 只影响 a
b.InstanceCount = 20;        // 只影响 b
Console.WriteLine($"{a.InstanceCount}, {b.InstanceCount}");   // 10, 20

Counter.TotalCount = 100;    // ★ 用【类名】访问静态字段，不是对象名
Console.WriteLine(Counter.TotalCount);    // 100
```

**关键区别**：

| | 实例成员 | 静态成员 |
|---|---|---|
| 属于谁 | **对象** | **类** |
| 内存里有几份 | 每个对象一份 | **全局一份** |
| 怎么访问 | `对象名.成员` | **`类名.成员`** |
| 有 `static` 吗 | 没有 | 有 |
| 能访问实例成员吗 | ✅ 能 | ❌ **不能** |

### ⚠️ 最重要的一条规则

```csharp
class Demo
{
    private int _instanceValue = 5;
    private static int _staticValue = 10;

    public void InstanceMethod()
    {
        Console.WriteLine(_instanceValue);   // ✅ 实例方法能访问实例字段
        Console.WriteLine(_staticValue);     // ✅ 也能访问静态字段
    }

    public static void StaticMethod()
    {
        Console.WriteLine(_staticValue);     // ✅ 静态方法能访问静态字段
        // Console.WriteLine(_instanceValue);  // ❌ 编译错误！
    }
}
```

**为什么静态方法不能访问实例字段？**
因为静态方法**不属于任何对象**，调用它的时候可能根本没有对象存在——
那 `_instanceValue` 是谁的值？所以编译器直接禁止。

> **这解释了为什么 `Main` 必须是 `static`**：
> 程序启动时**一个对象都还没创建**，运行时需要在不创建对象的情况下调用入口方法。
> 所以 `Main` 必须能"不依赖任何对象"运行 → 必须 `static`。

> **Python 对照**：
> - Python 的 `@staticmethod` ≈ C# 的 `static`
> - Python 的 `@classmethod` 收到的 `cls` ≈ C# 静态方法的上下文
> - **Python 的模块级变量/函数** ≈ C# 的静态字段/静态方法
> （Python 里在模块顶层写的东西，本质上就是"静态"的）

## 二、静态字段的典型用途：计数器

**想知道"一共创建了多少个对象"？** 实例字段做不到（每个对象各算各的），必须用静态字段：

```csharp
class Student
{
    public string Name { get; set; }
    public static int TotalCreated = 0;       // 静态：全局共享

    public Student(string name)
    {
        Name = name;
        TotalCreated++;                        // 每创建一个对象就 +1
    }
}
```

```csharp
new Student("张三");
new Student("李四");
new Student("王五");

Console.WriteLine($"一共创建了 {Student.TotalCreated} 个学生");   // 3
```

**为什么能工作？** 因为 `TotalCreated` 只有一份，所有构造函数都在改同一个变量。

**其他常见用途**：
- 统计总数、累计金额
- 全局配置（比如 `AppConfig.MaxRetryCount`）
- 缓存（比如已加载的数据）

> ⚠️ **静态字段的代价**：它**一直存在**，直到程序结束（不会随对象被回收）。
> 所以**不要往静态字段里塞大量数据**，那是内存泄漏。

## 三、静态方法

```csharp
class MathHelper
{
    public static int Square(int x) => x * x;
    public static bool IsEven(int n) => n % 2 == 0;
    public static double ToFahrenheit(double celsius) => celsius * 9 / 5 + 32;
}
```

**调用时不用创建对象**：

```csharp
Console.WriteLine(MathHelper.Square(5));               // 25
Console.WriteLine(MathHelper.ToFahrenheit(100));       // 212
```

**什么时候用静态方法？**

| 场景 | 例子 |
|---|---|
| **纯工具函数**（不依赖对象状态） | `Math.Sqrt`、`MathHelper.Square` |
| 工厂方法（创建对象） | `Student.CreateFromLine(text)` |
| **不依赖对象状态的逻辑** | `Calculator.CalculateTax(income)` |

**什么时候不该用静态方法？**

| 场景 | 为什么 |
|---|---|
| 需要访问实例字段 | 静态方法做不到 |
| 需要被继承和重写 | 静态方法不能被重写（第 07 课） |
| 需要多态 | 同上 |

> **判断标准**：**这个方法需要"某个对象的数据"吗？**
> 需要 → 实例方法。不需要 → 可以用静态方法。

## 四、静态类

如果**一个类里全是静态成员**，而且**根本不需要创建对象**，就把它声明为 `static class`：

```csharp
static class MathHelper        // ← 加 static
{
    public static int Square(int x) => x * x;
    public static bool IsEven(int n) => n % 2 == 0;
}

// MathHelper h = new MathHelper();    // ❌ 编译错误：静态类不能创建对象
```

**静态类的规则**：
- 不能 `new`
- 所有成员必须是 `static`
- 不能被继承

**.NET 里的例子**：`Math`、`Console`、`File`、`Array`、`Convert`、`string`（严格说是静态方法集合）

**Python 对照**：Python 里"一个模块里的函数集合"就相当于 C# 的静态类。
比如 Python 的 `math` 模块 → C# 的 `Math` 静态类。

## 五、静态构造函数

**普通的静态字段初始化**可以直接赋值：

```csharp
public static int Count = 0;
```

**但如果初始化需要多行代码呢？** 用静态构造函数：

```csharp
class Config
{
    public static string AppName;
    public static DateTime LoadedAt;

    // 静态构造函数：没有参数、没有访问修饰符、没有 static 关键字以外的修饰
    static Config()
    {
        AppName = "我的应用";
        LoadedAt = DateTime.Now;
        Console.WriteLine("静态构造函数执行了（只执行一次）");
    }
}
```

**静态构造函数的特点**：

| 特点 | 说明 |
|---|---|
| **只执行一次** | 在**第一次**访问这个类的任何静态成员之前 |
| **不能有参数** | 因为是运行时自动调用的 |
| **不能手动调用** | 你写 `Config()` 是调用普通构造函数 |
| **不能有访问修饰符** | 不能写 `public static Config()` |

**执行时机**（这个常考）：

```csharp
Console.WriteLine("1. 程序开始");
Console.WriteLine(Config.AppName);       // ← 第一次访问 → 静态构造函数在这里执行
Console.WriteLine("2. 之后");
Console.WriteLine(Config.AppName);       // ← 第二次访问 → 不再执行
```

输出：
```
1. 程序开始
静态构造函数执行了（只执行一次）
我的应用
2. 之后
我的应用
```

## 六、访问修饰符 —— 谁能看见谁

### 四个主要修饰符

| 修饰符 | 可见范围 | 类比 |
|---|---|---|
| `public` | **所有人**都能访问 | 大门口 |
| `private` | **只有本类内部**能访问 | 卧室 |
| `protected` | 本类 + **子类** | 家里（含继承的孩子） |
| `internal` | **同一个项目（程序集）**内 | 公司内部 |

```csharp
class BankAccount
{
    private decimal _balance;              // 只有本类能碰
    protected string OwnerId;              // 本类和子类能碰
    internal string BankCode;              // 同项目能碰
    public string AccountNumber { get; set; }   // 所有人能碰
}
```

### 默认（不写修饰符）是什么？

| 位置 | 默认修饰符 |
|---|---|
| `class` 本身 | `internal` |
| class 里的成员（字段、方法、属性） | **`private`** |
| 接口成员 | `public`（必须） |

> **⚠️ 这条很重要**：**类成员默认是 `private`！**
> 所以下面这两行是**不一样**的：
> ```csharp
> class A { int x; }              // x 是 private
> class B { public int x; }       // x 是 public
> ```

### 怎么选？一条实用原则

> **默认全部写 `private`，只有确实需要对外暴露时才改成 `public`。**

这叫做**最小权限原则**。为什么？

```csharp
// ❌ 全公开：外面什么都能改，数据随时可能被搞坏
class Student
{
    public int Grade;                  // 谁都能塞 999
    public decimal Balance;            // 谁都能改成负数
}

// ✅ 私有字段 + 公开属性：对外只暴露"受控的大门"
class Student
{
    private int _grade;
    public int Grade
    {
        get => _grade;
        set
        {
            if (value < 0 || value > 100) return;    // 有校验
            _grade = value;
        }
    }
}
```

> **Python 对照**：
> Python 只有**约定**（`_name` 表示"别碰我"），**没有强制**。
> C# 的 `private` 是**编译器强制**的：外面写 `obj._balance` 直接编译错误。
>
> 所以 C# 里"私有"是真私有，Python 里只是"请勿触摸"。

## 七、静态成员的访问修饰符组合

```csharp
class Demo
{
    private static int _secret = 42;          // 【只有本类能用】的共享数据
    public static int PublicShared = 100;     // 所有人都能用的共享数据

    public static int GetSecret() => _secret; // 通过公开方法间接访问
}
```

**常见组合**：

| 写法 | 含义 | 用在哪 |
|---|---|---|
| `public static` | 公开的共享工具 | `Math.Sqrt`、`Console.WriteLine` |
| `private static` | 类内部的共享状态 | 缓存、计数器的内部实现 |
| `public const` | 公开常量 | `Math.PI`、`int.MaxValue` |
| `private const` | 内部常量 | 只有本类用的魔法数字 |

## 八、`const` vs `static readonly`（顺便搞清）

这两个经常被搞混：

```csharp
class Config
{
    public const int MaxRetry = 3;                        // 编译期常量
    public static readonly DateTime StartTime = DateTime.Now;  // 运行期只读
    public static readonly int[] Defaults = { 1, 2, 3 };       // 数组也能这样
}
```

| | `const` | `static readonly` |
|---|---|---|
| 什么时候确定值 | **编译期** | **运行时** |
| 能是 `DateTime.Now` 吗 | ❌ 不能 | ✅ 能 |
| 能是数组吗 | ❌ 不能 | ✅ 能 |
| 默认就是静态的吗 | ✅ 是（不用写 static） | 要写 `static` |
| 用途 | 真正的常量（`Pi`、`MaxRetry`） | 运行期算出来但之后不改的值 |

> **`const` 只能是"编译期就能算出来的值"**：数字、字符串、bool、char。
> **其他情况用 `static readonly`。**

## 九、单例模式（了解即可）

**需求**：某个类**全局只能有一个对象**（比如配置管理器、日志管理器）。

```csharp
class AppConfig
{
    // ① 私有静态字段：存唯一的那个对象
    private static AppConfig? _instance;

    // ② 私有构造函数：禁止外面 new
    private AppConfig()
    {
        Console.WriteLine("AppConfig 被创建（只会看到一次）");
    }

    // ③ 公开静态方法：给外面一个拿对象的口子
    public static AppConfig GetInstance()
    {
        if (_instance is null)
        {
            _instance = new AppConfig();     // 第一次才创建
        }
        return _instance;
    }

    public string AppName { get; set; } = "我的应用";
}
```

```csharp
var c1 = AppConfig.GetInstance();
var c2 = AppConfig.GetInstance();
Console.WriteLine(c1 == c2);          // True —— 两次拿到的是同一个对象
```

**三个关键点**：
1. **私有构造函数** → 外面 `new AppConfig()` 会编译错误
2. **静态字段存实例** → 全局只有一份
3. **静态方法提供访问** → `GetInstance()`

> **本课只需要"看懂"单例**。它是"静态成员"最经典的应用场景，
> 但实际项目里现在更推荐用**依赖注入**（后面课程会讲）。

## 十、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `public static int X;` | 静态字段（全局共享） | 模块级变量 | 一直存在，别塞大数据 |
| `public int X;` | 实例字段（每对象一份） | `self.x` | — |
| `ClassName.StaticMember` | 访问静态成员 | `module.var` | **用类名，不是对象名** |
| `static void F()` | 静态方法 | `@staticmethod` | **不能访问实例成员** |
| `static class X` | 静态类 | 模块 | 不能 `new`，不能继承 |
| `static Config() { }` | 静态构造函数 | 模块初始化代码 | 只执行一次，不能手动调 |
| `public` | 谁都能访问 | 无（Python 全公开） | — |
| `private` | 只有本类 | `_name`（仅约定） | **C# 是强制的** |
| `protected` | 本类 + 子类 | `_name`（仅约定） | — |
| `internal` | 同项目 | 无 | — |
| 不写修饰符 | class 成员默认 **`private`** | 无 | **容易忘** |
| `const int X = 3;` | 编译期常量 | `X = 3`（约定） | 只能是字面量 |
| `static readonly` | 运行期只读 | — | 能放 `DateTime.Now` |
