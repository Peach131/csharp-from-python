# C# 课程总目录

> **一次只学一课。** 每课都是完整的：原理 → 语法 → 逐行解释 → 示例 → 你动手写。
> 打卡方式：学完一课，在下面的表格里勾上，然后看 `学习档案\学习日志.md` 记一行。

---

## 怎么使用这套课程

### 每一课的标准流程（5 步，别跳）

```
① 打开这一课的解决方案
   └─ 例：第 04 课 → 第04课-方法与参数\第04课.sln
      ★ 一个解决方案 = 一课，其他课根本不存在于这里

② 读课文          CSharp课程\第NN课-xxx\第NN课.md
   └─ 先读「原理」和「语法讲解」，不要急着看代码

③ 跑示例          把 LessonNNDemo 设为启动项目 → Ctrl+F5
   └─ 逐行读示例源码里的中文注释，对照输出看

④ 写练习          打开 LessonNNPractice\LessonNNPractice.cs
   └─ 按里面的 TODO 一步一步做，每个 TODO 都有预期输出
   └─ 改成启动项目后 Ctrl+F5 运行

⑤ 交作业 + 记日志
   ★ 把代码 + 运行结果发给老师 → 老师给逐题批改
   ★ 老师会把记录写进 学习档案\学习日志.md
   ★ 你负责补每个条目的「我的反思」三行
     （卡在哪 / 想通了什么 / 还没搞懂的）
```

> **第 ⑤ 步为什么不能省**：
> 因为"我学会了什么"必须**由你自己说出来才算真学会**。
> 老师替你总结的，你三天就忘；自己写下来的，三个月后还能想起来。
>
> **「还没搞懂的」这一栏写不出来，说明这课钻得不够深。**

### 每课文件夹里有什么（每课自成一体）

```
第NN课-主题名\
├── 第NN课.md                     ← 课文（原理 + 语法 + 逐行解释 + 验收自测）
├── 第NN课.sln                    ← ★ 这一课的解决方案（在 Rider 里打开这个）
├── LessonNNDemo\                 ← 示例项目（能直接运行）
│   ├── LessonNNDemo.csproj
│   └── Program.cs
└── LessonNNPractice\             ← 练习项目（你的代码写在这里）
    ├── LessonNNPractice.csproj
    └── LessonNNPractice.cs
```

**每个解决方案里只有这一课的 2 个项目** —— 学第 04 课时，其他 16 课不参与编译、
不产生警告、不会出现在输出里。**完全不用改任何配置文件。**

**复习旧课**：直接打开那一课的 `.sln` 就行。
**给某课加总结/扩展**：在那个课文件夹里新建 `我的总结.md` 或新项目，互不干扰。

> 详细说明见 `学习档案\课程项目结构说明.md`

### 关键提醒

- **每课一个独立解决方案**，打开哪一课的 `.sln` 就只编译那一课。
  **不需要改任何配置文件。**
- **改代码之前先按 `Ctrl + F2` 停掉正在运行的程序**（否则报文件锁 MSB3027）。
- **看不懂的语法立刻问**，不要"先跳过"。C# 的语法是层层叠加的，跳过会越来越看不懂。

## 为什么是这个顺序

```
【先学语法】第 00-10 课
   你不会读代码，讲什么底层都是天书。
   ↓
【再学类型本质】第 11-14 课
   这是 Python 转 C# 最大的坎，也是所有底层知识的地基。
   ↓
【最后学底层机制】第 15-24 课
   有了前面的基础，这些才讲得通、你才听得懂。
   ↓
【Unity 落地】第 25-26 课
   把学到的底层知识用来做出一个流畅的游戏。
```

> ⚠️ **不要跳步。** 你之前直接看第 11 课的内容（`struct`/`class`/装箱），
> 结果卡住了——不是因为那些知识难，而是因为**缺了第 00-10 课的语法基础**。
> 现在我们把地基补上。
