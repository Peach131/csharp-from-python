## 一、字符串最重要的特性：**不可变**

```csharp
string s = "hello";
s.ToUpper();                  // 返回 "HELLO"，但……
Console.WriteLine(s);         // 还是 "hello"！
```

**为什么？** 因为 **`string` 是不可变（immutable）的** ——
**任何"修改"操作都是在堆上创建一个全新的字符串，原字符串永远不变。**

**这就是第 01 课说的"必须重新赋值"**：

```csharp
string s = "hello";
s = s.ToUpper();              // ✅ 把新字符串赋回去
Console.WriteLine(s);         // HELLO
```

### 为什么 C# 要把字符串设计成不可变？

| 原因 | 说明 |
|---|---|
| **线程安全** | 多个线程读同一个字符串不会有问题（没人能改它） |
| **可以安全共享** | 字符串"驻留"池复用同一份数据（省内存） |
| **哈希值可缓存** | 当字典的键时不用每次重算哈希 |
| **作为参数安全** | 方法拿到字符串，不用担心被别处改掉 |

### ⚠️ 由此产生的性能灾难：循环里拼接

```csharp
// ❌ O(n²)：每次 += 都创建一个新字符串，把全部内容复制一遍
string result = "";
for (int i = 0; i < 10000; i++)
{
    result += i;
}
```

**每次 `+=` 的代价**：
1. 分配一块**更大的**新内存（装下旧内容 + 新内容）
2. 把旧内容**全部复制**过去
3. 把新内容追加进去
4. 旧字符串变成垃圾，等 GC 回收

**n 次拼接 = 复制 `1+2+3+...+n ≈ n²/2` 个字符。**

### ✅ 正确做法：`StringBuilder`

```csharp
var sb = new StringBuilder();          // 内部是可变的 char 数组
for (int i = 0; i < 10000; i++)
{
    sb.Append(i);                      // 追加，不创建新对象
}
string result = sb.ToString();         // 最后一次性生成字符串
```

**实测对比**（本课示例代码的真实输出，10000 次拼接）：

| 方式 | 耗时 | 分配内存 |
|---|---|---|
| `s += i` | 慢**几十到上百倍** | 几十 MB |
| `StringBuilder` | 快 | 几百 KB |

> **规则**：
> - **少量拼接（2-5 个）** → 直接用 `+` 或 `$""`，没问题
> - **循环里拼接 / 拼接很多次** → **必须用 `StringBuilder`**

### 现代替代方案

```csharp
// 已知所有片段时，用 string.Join 最简洁
string joined = string.Join(", ", items);

// 已知最终长度时，用 string.Concat
string result = string.Concat(parts);
```

## 二、`$""` 插值格式化（复习 + 扩展）

第 01 课讲过基础，这里补全常用格式符：

```csharp
double price = 1234.5678;
int count = 1234567;
double rate = 0.12345;

Console.WriteLine($"{price:F2}");        // 1234.57      固定 2 位小数
Console.WriteLine($"{price:N2}");        // 1,234.57     千分位 + 2 位小数
Console.WriteLine($"{price:C}");         // ¥1,234.57    货币格式
Console.WriteLine($"{price:E2}");        // 1.23E+003    科学计数法
Console.WriteLine($"{count:N0}");        // 1,234,567    千分位无小数
Console.WriteLine($"{rate:P1}");         // 12.3%        百分比 1 位小数
Console.WriteLine($"{rate:P2}");         // 12.35%       百分比 2 位小数

// 对齐（宽度）
Console.WriteLine($"[{42,10}]");         // [        42]  右对齐占 10 格
Console.WriteLine($"[{42,-10}]");        // [42        ]  左对齐占 10 格

// 组合：宽度 + 格式
Console.WriteLine($"[{price,12:F2}]");   // [     1234.57]

// 日期格式化
var now = DateTime.Now;
Console.WriteLine($"{now:yyyy-MM-dd}");           // 2026-09-23
Console.WriteLine($"{now:yyyy-MM-dd HH:mm:ss}");  // 2026-09-23 22:40:43
Console.WriteLine($"{now:HH:mm}");                // 22:40
Console.WriteLine($"{now:dddd}");                 // 星期三（星期几，跟系统语言）
```

> **Python 对照**：`f"{price:.2f}"` → C# `$"{price:F2}"`。
> 位置一样（冒号后），但**格式符名称不同**。

## 三、字符串常用方法（速查）

```csharp
string s = "  Hello World  ";

// 长度和访问
s.Length                    // 15（含空格）
s[0]                        // ' '
s[^1]                       // ' '（倒数第一个）
s[1..4]                     // " He"（范围切片，C# 8+）

// 清理
s.Trim()                    // "Hello World"    去首尾空白
s.TrimStart()               // "Hello World  "  只去开头
s.TrimEnd()                 // "  Hello World"  只去结尾
s.Trim(' ')                 // 去指定的字符

// 大小写
s.ToUpper()                 // 全大写
s.ToLower()                 // 全小写

// 查找
s.Contains("World")         // true
s.StartsWith("  He")        // true
s.EndsWith("  ")            // true
s.IndexOf("World")          // 8      找不到返回 -1
s.LastIndexOf("o")          // 最后一个 o 的位置

// 截取和替换
s.Substring(2, 5)           // 从索引 2 开始取 5 个字符
s.Replace("World", "C#")    // 替换（返回新字符串）

// 拆分和连接
"a,b,c".Split(',')          // string[] { "a", "b", "c" }
string.Join("-", arr)       // 用 - 连接数组

// 判断空
string.IsNullOrEmpty(s)         // 是 null 或 ""
string.IsNullOrWhiteSpace(s)    // 是 null 或 全是空白字符 ★ 更实用
```

### ⚠️ 三个容易踩的坑

**坑 1：`Substring` 越界会抛异常**

```csharp
string s = "abc";
// s.Substring(1, 5);        // ❌ ArgumentOutOfRangeException（只有 3 个字符）

// ✅ 先判断长度
if (s.Length >= 6) { var sub = s.Substring(1, 5); }
```

**坑 2：字符串比较要用 `==` 或 `Equals`，别用 `ReferenceEquals`**

```csharp
string a = "hello";
string b = "hel" + "lo";        // 编译期常量折叠，还是字面量
string c = string.Concat("hel", "lo");   // 运行时拼接

Console.WriteLine(a == b);              // True（按内容比）
Console.WriteLine(a == c);              // True（按内容比）
Console.WriteLine(ReferenceEquals(a, c)); // False（不同对象）
```

**`==` 对字符串是重载过的，按内容比较**（第 05 课讲过：自定义 class 的 `==` 是比地址的）。

**坑 3：忽略大小写比较**

```csharp
string x = "Hello";
string y = "HELLO";

Console.WriteLine(x == y);                                    // False
Console.WriteLine(x.Equals(y, StringComparison.OrdinalIgnoreCase));   // True ★
```

> **`StringComparison.OrdinalIgnoreCase` 是推荐写法**，
> 比 `x.ToLower() == y.ToLower()` 更快也更安全（不受本地语言设置影响）。

## 四、`DateTime` —— 日期时间

```csharp
var now = DateTime.Now;                    // 当前本地时间
var utc = DateTime.UtcNow;                 // 当前 UTC 时间
var today = DateTime.Today;                // 今天 00:00:00
var specific = new DateTime(2026, 9, 23, 22, 40, 0);   // 年,月,日,时,分,秒

// 取各部分
now.Year        // 2026
now.Month       // 9
now.Day         // 23
now.Hour        // 22
now.DayOfWeek   // Wednesday

// 运算
var tomorrow = now.AddDays(1);
var nextWeek = now.AddDays(7);
var lastMonth = now.AddMonths(-1);
var diff = tomorrow - now;                 // TimeSpan
Console.WriteLine(diff.TotalHours);        // 24

// 格式化
Console.WriteLine(now.ToString("yyyy-MM-dd"));
Console.WriteLine(now.ToString("yyyy年MM月dd日 HH:mm"));
```

### `TimeSpan` —— 时间间隔

```csharp
var ts = new TimeSpan(2, 30, 15);          // 2 小时 30 分 15 秒
Console.WriteLine(ts);                     // 02:30:15
Console.WriteLine(ts.TotalMinutes);        // 150.25
Console.WriteLine(ts.Hours);               // 2（注意：不是总小时数）
```

> **⚠️ 常用坑**：`ts.Hours` 是"小时部分"，`ts.TotalHours` 才是"总小时数"。
> 2 天 5 小时的 `ts.Hours` 是 5，`ts.TotalHours` 是 53。

### 解析日期字符串

```csharp
if (DateTime.TryParse("2026-09-23", out DateTime parsed))
{
    Console.WriteLine(parsed.ToString("yyyy/MM/dd"));
}
// 和 int.TryParse 一个套路：失败的返回 false，不抛异常
```

## 五、`Math` 和 `Convert`

### `Math`（第 02 课讲过一部分，这里补全）

```csharp
Math.Abs(-5)             // 5
Math.Max(3, 7)           // 7
Math.Min(3, 7)           // 3
Math.Round(3.567, 2)     // 3.57     四舍五入
Math.Floor(3.9)          // 3        向下取整
Math.Ceiling(3.1)        // 4        向上取整
Math.Pow(2, 10)          // 1024
Math.Sqrt(16)            // 4
Math.PI                  // 3.14159...（常量，不加括号）
```

### `Convert`（类型转换的"万能工具"）

```csharp
Convert.ToInt32("123")       // 123
Convert.ToDouble("3.14")     // 3.14
Convert.ToString(123)        // "123"
Convert.ToBoolean("true")    // true

// 和 Parse 的区别：Convert 能处理 null
Convert.ToInt32(null)        // 0（不抛异常）
// int.Parse(null)           // ❌ ArgumentNullException
```

**该用哪个？**

| 场景 | 用什么 |
|---|---|
| 用户输入（可能不合法） | **`TryParse`**（最安全） |
| 确定合法的数据 | `Parse` |
| 值可能是 null，想要默认值 | `Convert` |

## 六、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| 字符串**不可变** | 任何"修改"都创建新字符串 | 同 | 忘了重新赋值 |
| `new StringBuilder()` | 可变字符串缓冲区 | `io.StringIO` | **循环拼接必须用** |
| `sb.Append(x)` | 追加 | `write(x)` | — |
| `sb.ToString()` | 生成最终字符串 | `getvalue()` | — |
| `$"{x:F2}"` | 2 位小数 | `{x:.2f}` | 格式符名不同 |
| `$"{x,10}"` | 右对齐占 10 格 | `{x:>10}` | — |
| `s[1..4]` | 切片 | `s[1:4]` | C# 8+ |
| `s.Split(',')` | 拆分 | `s.split(',')` | — |
| `string.Join("-", arr)` | 连接 | `"-".join(arr)` | **参数顺序相反** |
| `s.Equals(y, StringComparison.OrdinalIgnoreCase)` | 忽略大小写比较 | `s.lower()==y.lower()` | 推荐写法 |
| `DateTime.Now` / `UtcNow` | 当前时间 | `datetime.now()` | — |
| `now.AddDays(1)` | 日期运算 | `now + timedelta(days=1)` | — |
| `TimeSpan.TotalHours` | 总小时数 | — | **不是 `.Hours`** |
| `Convert.ToInt32(x)` | 万能转换 | `int(x)` | 能处理 null |
