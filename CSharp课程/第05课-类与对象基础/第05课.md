## 一、为什么需要类

### 先看现在的问题

第 04 课的成绩报告里，我们用**两个数组**存学生的姓名和成绩：

```csharp
string[] names  = { "张三", "李四", "王五" };
int[]    grades = { 88, 92, 76 };
```

**问题在哪？** 姓名和成绩是**分开的两组数据**，靠"索引相同"来关联：

```csharp
Console.WriteLine($"{names[i]}：{grades[i]}");    // 靠 i 相同来对应
```

**风险**：
- 如果两个数组长度不一致（比如删了一个人只删了一个数组），程序就错了
- 想加一个字段（比如年龄），就要再加一个数组
- 想在数组间排序，会非常麻烦

### 类怎么解决

```csharp
class Student
{
    public string Name;        // 字段：姓名
    public int Grade;          // 字段：成绩
}
```

**现在姓名和成绩被"绑"在一起了**：

```csharp
Student s = new Student();
s.Name = "张三";
s.Grade = 88;

Console.WriteLine($"{s.Name}：{s.Grade}");    // 不用索引，直接访问
```

**这就是类的本质**：

> **类把"相关的数据"和"操作这些数据的方法"打包在一起。**

> **Python 对照**：你熟悉的 Python 类是一样的概念。
> ```python
> class Student:
>     def __init__(self):
>         self.name = ""
>         self.grade = 0
> ```
> C# 的 `class` 和 Python 的 `class` 概念一致，**区别在于 C# 要求声明字段类型**。

## 二、两个核心概念：类 和 对象

**这两个词经常被混用，但含义不同：**

| 概念 | 含义 | 类比 |
|---|---|---|
| **类（class）** | **模板 / 图纸** —— 描述"这类东西长什么样" | 月饼模具 |
| **对象（object）** | 用类**创建出来的具体实例** | 用模具压出来的月饼 |

```csharp
class Student              // ← 这是一个【类】，是模板
{
    public string Name;
    public int Grade;
}

// 用模板创建出具体的对象
Student a = new Student();     // ← a 是一个【对象】
Student b = new Student();     // ← b 是另一个【对象】

a.Name = "张三";               // a 和 b 是独立的，互不影响
b.Name = "李四";
```

**对象又叫"实例"（instance）**，"创建一个对象"也叫"实例化"。

> **术语对照**：`new Student()` 读作"new 一个 Student"或"实例化一个 Student"。

## 三、字段（Field）—— 对象的数据

```csharp
class Student
{
    public string Name;        // 字段：字符串
    public int Grade;          // 字段：整数
    public bool IsPassed;      // 字段：布尔
    public double Height;      // 字段：小数
}
```

**语法结构**：

```
public  string  Name  ;
  │       │      │    └── 分号（字段声明也要分号）
  │       │      └─────── 字段名，惯例 PascalCase（首字母大写）
  │       └────────────── 类型
  └────────────────────── 访问修饰符 public
```

### ⚠️ 字段的默认值

**用 `new` 创建对象后，字段会自动获得"默认值"**：

```csharp
Student s = new Student();
Console.WriteLine(s.Name);       // 输出空（null）
Console.WriteLine(s.Grade);      // 输出 0
Console.WriteLine(s.IsPassed);   // 输出 False
Console.WriteLine(s.Height);     // 输出 0
```

| 类型 | 默认值 |
|---|---|
| `int` / `double` / `decimal` | `0` |
| `bool` | `false` |
| `char` | `'\0'`（空字符） |
| `string` 和其他引用类型 | **`null`** |

> ⚠️ **`string` 字段默认是 `null`，不是空字符串 `""`！**
> 直接用它（比如 `s.Name.Length`）会**崩溃**（`NullReferenceException`）。
> 这是下一课"可空"要解决的问题。

## 四、⚠️ 字段为什么不直接暴露：属性（Property）

**上面那样写 `public string Name;` 能跑，但生产代码里不这么写。** 为什么？看这个例子：

```csharp
class Student
{
    public int Grade;          // 直接暴露字段
}

Student s = new Student();
s.Grade = 99999;               // ← 没人拦得住你！成绩不能是 99999
s.Grade = -50;                 // ← 也不能是负数
```

**字段是"裸奔"的，任何人都能塞进任何值。**

### 用属性加"门禁"

```csharp
class Student
{
    private int _grade;        // 私有字段：外面看不见

    public int Grade           // 属性：对外的大门
    {
        get { return _grade; }
        set
        {
            if (value < 0 || value > 100)
            {
                Console.WriteLine($"成绩 {value} 不合法，已忽略");
                return;                    // 不赋值，直接返回
            }
            _grade = value;
        }
    }
}
```

**现在外面的非法值进不来了**：

```csharp
Student s = new Student();
s.Grade = 88;                  // ✅ 正常赋值
s.Grade = 999;                 // ❌ 输出"成绩 999 不合法，已忽略"，字段保持不变
```

### 属性语法拆解

```csharp
public int Grade
{
    get { return _grade; }      // 读的时候执行这里
    set { _grade = value; }     // 写的时候执行这里
}
```

| 关键字 | 什么时候执行 | 特殊变量 |
|---|---|---|
| `get` | 有人**读**这个属性时（`x = s.Grade`） | — |
| `set` | 有人**写**这个属性时（`s.Grade = 88`） | `value` = 要赋的新值 |

### 自动属性（最常用的简写）

如果 `get`/`set` 里**没有特殊逻辑**，可以简写：

```csharp
// 完整写法（啰嗦）
private string _name;
public string Name
{
    get { return _name; }
    set { _name = value; }
}

// 自动属性（等价，推荐）
public string Name { get; set; }
```

**`{ get; set; }` 是编译器帮你生成了那个隐藏的私有字段**，你看不见但它在。

> **Python 对照**：
> Python 用 `@property` 装饰器实现同样的效果。
> ```python
> class Student:
>     @property
>     def grade(self):
>         return self._grade
>     @grade.setter
>     def grade(self, value):
>         if 0 <= value <= 100:
>             self._grade = value
> ```
> **C# 的属性是语言内置的一等公民**，而 Python 靠装饰器模拟。
> 所以 C# 里"用属性而不是裸字段"是**默认习惯**，Python 里反而少见。

## 五、构造函数（Constructor）—— 创建对象时自动执行

**问题**：每次创建对象都要逐个赋值，很啰嗦：

```csharp
Student s = new Student();
s.Name = "张三";
s.Grade = 88;
s.Height = 1.75;
```

### 用构造函数一次搞定

```csharp
class Student
{
    public string Name { get; set; }
    public int Grade { get; set; }

    // 构造函数：名字必须和类名完全一样，而且【没有返回类型】
    public Student(string name, int grade)
    {
        Name = name;
        Grade = grade;
    }
}

// 现在创建对象时可以一次传完
Student s = new Student("张三", 88);
```

**构造函数的三个特点**：

| 特点 | 说明 |
|---|---|
| 名字**必须和类名完全一样** | `class Student` → `public Student(...)` |
| **没有返回类型** | 连 `void` 都不写 |
| `new` 的时候**自动调用** | `new Student("张三", 88)` 就是在调用它 |

> **Python 对照**：C# 的构造函数 = Python 的 `__init__`。
> 区别：Python 写 `def __init__(self, name):`，C# 写 `public Student(string name)`。
> Python 有显式的 `self`，C# 用 `this`（而且大多数时候可以省略）。

### 多个构造函数（重载）

和第 04 课的方法重载一样：

```csharp
class Student
{
    public string Name { get; set; }
    public int Grade { get; set; }

    public Student(string name, int grade)     // 两个参数
    {
        Name = name;
        Grade = grade;
    }

    public Student(string name) : this(name, 0)   // 一个参数，调用上面的构造函数
    {
    }

    public Student()                              // 无参数
    {
        Name = "未命名";
        Grade = 0;
    }
}

// 三种创建方式都行
var a = new Student("张三", 88);
var b = new Student("李四");
var c = new Student();
```

> **`this(name, 0)` 是什么意思？**
> `: this(...)` 表示"先调用另一个构造函数"，避免重复写赋值代码。

## 六、`this` —— 指向"当前这个对象"

```csharp
class Student
{
    private string name;

    public Student(string name)     // 参数名和字段名重名了！
    {
        this.name = name;           // this.name 是字段，name 是参数
    }
}
```

**`this` 就是"我自己这个对象"**。

**什么情况必须写 `this`？** 只有当**参数名和字段名冲突**时。
其他时候可以省略：

```csharp
public Student(string name, int grade)
{
    Name = name;          // 没冲突，不用写 this
    Grade = grade;
}
```

> **Python 对照**：Python 的 `self` 是**必须显式写的第一个参数**；
> C# 的 `this` 是**隐含的**，只在需要区分时才写。
> 这是两个语言写法上最明显的差异之一。

## 七、对象初始化器 —— 另一种创建对象的方式

```csharp
class Student
{
    public string Name { get; set; }
    public int Grade { get; set; }
}

// 方式 1：先 new，再逐个赋值
var s1 = new Student();
s1.Name = "张三";
s1.Grade = 88;

// 方式 2：对象初始化器（大括号里直接赋值）
var s2 = new Student { Name = "张三", Grade = 88 };
```

**对象初始化器 = `new` + 紧接着用 `{ }` 给属性赋值**，语法更紧凑。

**要求**：属性必须有 `set`（或者 `init`，见下）。

## 八、只读属性：`{ get; }` 和 `{ get; init; }`

### `{ get; }` —— 只能在构造函数里赋值

```csharp
class Student
{
    public string Name { get; }        // 只有 get，没有 set

    public Student(string name)
    {
        Name = name;                   // ✅ 构造函数里可以赋值
    }
}

var s = new Student("张三");
// s.Name = "李四";                    // ❌ 编译错误：属性是只读的
```

### `{ get; init; }` —— 可以在初始化时赋值（C# 9+）

```csharp
class Student
{
    public string Name { get; init; }
    public int Grade { get; init; }
}

var s = new Student { Name = "张三", Grade = 88 };   // ✅ 初始化器里可以赋值
// s.Name = "李四";                                   // ❌ 之后就不能改了
```

| 写法 | 构造函数里能赋值 | 初始化器里能赋值 | 之后能改 |
|---|---|---|---|
| `{ get; set; }` | ✅ | ✅ | ✅ |
| `{ get; init; }` | ✅ | ✅ | ❌ |
| `{ get; }` | ✅ | ❌ | ❌ |

**建议**：**能用 `init` 就用 `init`**。不可变的对象更安全，不容易被意外改动。

## 九、`record` —— 一行搞定不可变数据类（C# 9+）

如果这个类**只是用来装数据**，用 `record` 最省事：

```csharp
// 传统 class 写一大堆
class Point
{
    public int X { get; init; }
    public int Y { get; init; }
    public Point(int x, int y) { X = x; Y = y; }
    public override string ToString() => $"({X}, {Y})";
    // 还要自己写 Equals 和 GetHashCode 才能按值比较...
}

// record 只要一行
record Point(int X, int Y);
```

**`record` 自动帮你生成**：
- 构造函数
- 属性（默认 `init`，不可变）
- `ToString()`
- **按值比较的 `Equals` 和 `GetHashCode`**（这一点很重要）

```csharp
var p1 = new Point(1, 2);
var p2 = new Point(1, 2);

Console.WriteLine(p1);              // (1, 2)
Console.WriteLine(p1 == p2);        // True —— record 是【按值】比较！
```

> **注意**：普通 `class` 用 `==` 是**按地址**比较的：
> ```csharp
> var s1 = new Student("张三", 88);
> var s2 = new Student("张三", 88);
> Console.WriteLine(s1 == s2);      // False！因为是两个不同的对象
> ```
> 而 `record` 重载了 `==`，按内容比。

> **Python 对照**：`record` ≈ Python 的 `@dataclass`。
> ```python
> from dataclasses import dataclass
> @dataclass
> class Point:
>     x: int
>     y: int
> ```

**什么时候用 `record`？**
- 数据传输对象（DTO）、配置项、坐标、金额、API 返回值
- **总之：只装数据、不需要行为、希望按值比较的东西**

## 十、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `class Student { }` | 定义类（模板） | `class Student:` | — |
| `public string Name;` | 字段 | `self.name = ""` | **默认值是 null** |
| `new Student()` | 创建对象 | `Student()` | — |
| `public string Name { get; set; }` | 自动属性 | `@property` | **推荐用它代替裸字段** |
| `get { } / set { }` | 属性的读写逻辑 | property getter/setter | `set` 里用 `value` |
| `private int _grade;` | 私有字段 | `self._grade` | `_` 前缀是惯例 |
| `public Student(string n) { }` | 构造函数 | `def __init__(self, n):` | **名字必须=类名，无返回类型** |
| `new Student("张三", 88)` | 用构造函数创建 | `Student("张三", 88)` | — |
| `this.name = name;` | 区分字段和参数 | `self.name = name` | Python 的 self 必写 |
| `new Student { Name = "x" }` | 对象初始化器 | — | 需要 `set` 或 `init` |
| `{ get; }` | 只读（仅构造函数可赋值） | 只读 property | — |
| `{ get; init; }` | 初始化时可赋值 | `frozen dataclass` | C# 9+ 才有 |
| `record Point(int X, int Y);` | 不可变数据类 | `@dataclass` | **按值比较** |
| `==` 比较 class | 按**地址**比 | `is` | 想按值比要用 record |
