## 一、为什么需要方法

先看一段真实的代码（你第 03 课的 TODO 6）：

```csharp
static void Main()
{
    // ... 找最高分
    int maxScore = grades[0];
    for (int i = 1; i < grades.Length; i++)
        if (grades[i] > maxScore) maxScore = grades[i];

    // ... 打印报告
    for (int i = 0; i < grades.Length; i++) { ... }

    // ... 算平均分
    int count = 0;
    for (...) count += grades[i];
}
```

**问题**：`Main` 方法越来越长，所有逻辑堆在一起。

**如果需求变成"要处理 3 个班级的成绩"呢？** 你只能把上面的代码复制三遍。
**复制粘贴三次之后，如果发现一个 bug，你要改三个地方。**

**方法的本质**：把一段代码"打包"，起个名字，需要时调用。

```csharp
static int FindMax(int[] numbers)          // 打包：这段代码叫 FindMax
{
    int max = numbers[0];
    for (int i = 1; i < numbers.Length; i++)
        if (numbers[i] > max) max = numbers[i];
    return max;
}

static void Main()
{
    int max1 = FindMax(classA);            // 调用：用名字，不用复制代码
    int max2 = FindMax(classB);
    int max3 = FindMax(classC);
}
```

**方法带来三个好处**：

| 好处 | 说明 |
|---|---|
| **不用重复** | 写一次，调用多次 |
| **改了只改一处** | 有 bug 只修 `FindMax` 内部 |
| **能看懂在干什么** | `FindMax(scores)` 比 10 行循环更说明意图 |

> **Python 对照**：Python 的 `def` 和 C# 的方法几乎一样。
> 区别是 C# 的方法**必须写在类里面**，而且**必须写明返回类型**。

## 二、方法的定义语法

```csharp
static int Add(int a, int b)
{
    return a + b;
}
```

**逐个词拆解**：

```
static  int   Add  ( int a , int b )
  │      │     │     └──┬──┘
  │      │     │        └── 参数列表：类型 名字，用逗号分隔
  │      │     └────────── 方法名：你自己起，惯例 PascalCase（首字母大写）
  │      └──────────────── 返回类型：这个方法返回什么类型的值
  └─────────────────────── 修饰符 static：暂时都加，第 06 课解释
```

**对比一个不返回值的方法**：

```csharp
static void PrintLine()
{
    Console.WriteLine("----------");
}
// void 表示"没有返回值"，所以不需要 return
```

**返回类型有哪几种情况**：

| 返回类型 | 含义 | 有没有 `return` |
|---|---|---|
| `void` | 什么都不返回 | 可以没有，或者写 `return;` 直接结束 |
| `int` / `double` / `string` / `bool` | 返回一个该类型的值 | **必须有 `return 值;`** |
| `(int, int)` | 返回元组（多个值） | 必须有 `return (a, b);` |

### ⚠️ 三个必须遵守的规则

```csharp
// ① 方法必须写在类里面
class Program
{
    static void MyMethod() { }        // ✅ 在类里面
}
// static void MyMethod() { }         // ❌ 在类外面 → 编译错误

// ② 有返回类型的方法，所有分支都必须有 return
static int GetGrade(int score)
{
    if (score >= 60)
    {
        return 1;
    }
    // ❌ 编译错误：不是所有代码路径都返回值
}
static int GetGradeFixed(int score)
{
    if (score >= 60) return 1;
    return 0;                         // ✅ 保证所有路径都有返回值
}

// ③ 方法不能写在另一个方法里面
static void A()
{
    // static void B() { }            // ❌ 不允许
}
```

> **记住第 ① 条**：这是 C# 和 Python 最大的结构差异。
> **Python 可以在文件里定义任何函数；C# 的方法必须属于某个类。**

## 三、`return` 的两个作用

```csharp
static int Divide(int a, int b)
{
    if (b == 0)
    {
        Console.WriteLine("除数不能为 0");
        return 0;                  // 作用 1：返回值
    }
    return a / b;
}
```

```csharp
static void CheckAge(int age)
{
    if (age < 0)
    {
        Console.WriteLine("年龄不合法");
        return;                    // 作用 2：立刻结束方法（void 方法里不返回值）
    }
    Console.WriteLine($"年龄是 {age}");
}
```

**`return` 一旦执行，方法就立刻结束**，后面的代码不会跑：

```csharp
static void Demo()
{
    Console.WriteLine("A");
    return;                        // ← 方法在这里就结束了
    Console.WriteLine("B");        // 这行永远不会执行（编译器会警告"无法访问的代码"）
}
```

> **这就是你在第 01、02 课用过的"卫语句"**：
> ```csharp
> if (!double.TryParse(input, out double x))
> {
>     Console.WriteLine("输入不合法");
>     return;                    // 提前结束，避免后面拿无效数据算
> }
> ```

## 四、⚠️ 本课最重要的一节：参数传递

**这一节必须彻底搞懂**，因为它是最容易出"改了半天没生效"或"莫名其妙被改了"的地方。

### 情况 1：值类型参数 —— 传的是**副本**

```csharp
static void TryChange(int x)
{
    x = 999;                       // 改的是副本
}

static void Main()
{
    int n = 5;
    TryChange(n);
    Console.WriteLine(n);          // 输出 5，不是 999
}
```

**内存图示**：

```
调用 TryChange(n) 时：
    Main 的 n  → [ 5 ]
                   ↓ 复制一份
    TryChange 的 x → [ 5 ]   ← 方法里改的是这个
                      ↓ 改成 999
    TryChange 的 x → [ 999 ]

方法结束后 x 消失，Main 的 n 还是 [ 5 ]
```

**适用类型**：`int`、`double`、`bool`、`char`、`struct`、`decimal`、`long` 等。

### 情况 2：引用类型参数 —— 传的是**地址副本**，但指向同一个对象

```csharp
static void FillArray(int[] arr)
{
    for (int i = 0; i < arr.Length; i++)
    {
        arr[i] = 0;                // 改的是【数组里的元素】
    }
}

static void Main()
{
    int[] nums = { 1, 2, 3 };
    FillArray(nums);
    Console.WriteLine(string.Join(",", nums));   // 输出 0,0,0 —— 变了！
}
```

**为什么这次变了？** 因为参数 `arr` 和外面的 `nums` 是**两份地址副本，但指向同一个数组对象**。
通过地址找到数组，改的是数组里面的内容 —— **改动会反映到外面**。

```
Main 的 nums  → ┐
                ├──→ 堆上的数组 [1, 2, 3]
FillArray 的 arr → ┘
                    方法里 arr[i] = 0 改的是【堆上那个数组】
```

### ⚠️ 情况 2 的反直觉陷阱：字符串

**`string` 也是引用类型，但行为却像值类型：**

```csharp
static void TryChangeString(string s)
{
    s = "改了";                    // 只是让副本指向了另一个字符串
}

static void Main()
{
    string text = "原来";
    TryChangeString(text);
    Console.WriteLine(text);       // 输出"原来" —— 没变！
}
```

**为什么？** 两个原因叠加：

1. **`s = "改了"` 不是"修改字符串内容"，而是"让 `s` 指向一个新的字符串对象"**
   （字符串是**不可变**的，第 01 课讲过）
2. 所以这相当于只是改了**副本的指向**，外面的 `text` 还指着原来那个

```
Main 的 text → "原来"
                 ↑ 复制地址
TryChangeString 的 s → "原来"
                        ↓ s = "改了" 让 s 改指向新对象
TryChangeString 的 s → "改了"        ← text 完全没受影响
```

**但如果改的是字符串的"成员"行为**（比如通过数组），又会变：

```csharp
static void ChangeFirstChar(char[] chars) { chars[0] = 'X'; }   // 数组 → 会变
```

### 三种情况的总结表（**建议背下来**）

| 参数类型 | 方法内 `参数 = 新值` | 方法内改参数指向的对象的内容 |
|---|---|---|
| 值类型（`int` 等） | ❌ 外面不变 | — |
| 引用类型（数组、List、自定义 class） | ❌ 外面不变 | ✅ **外面会变** |
| `string`（特殊的引用类型） | ❌ 外面不变 | 无法修改（内容不可变） |

> **一句话记法**：
> **"重新赋值"永远只影响方法内部；"通过引用改内容"才会影响外面。**

## 五、`ref` 和 `out` —— 让方法能改外部变量

### `ref`：要把外部变量改成新值

```csharp
static void Increment(ref int x)
{
    x++;                           // 因为加了 ref，这里改的是【外部那个变量】
}

static void Main()
{
    int n = 5;
    Increment(ref n);              // ★ 调用时也要写 ref
    Console.WriteLine(n);          // 输出 6 —— 真的变了
}
```

**`ref` 的规则**：
- 定义时参数前加 `ref`
- **调用时也必须写 `ref`**
- 传入的变量**必须先赋值**（初始化过）

### `out`：方法要"额外返回"一个值

你已经用过很多次了，现在正式解释它：

```csharp
static bool TryDivide(int a, int b, out int result)
{
    if (b == 0)
    {
        result = 0;                // ★ 必须先给 out 参数赋值
        return false;              // 返回 false 表示"失败"
    }
    result = a / b;
    return true;                   // 返回 true 表示"成功"
}

static void Main()
{
    if (TryDivide(10, 2, out int r))
        Console.WriteLine($"成功：{r}");       // 成功：5
    else
        Console.WriteLine("失败");
}
```

**为什么要用 `out`？** 因为一个方法只能 `return` **一个**值。
但 `TryParse` 需要告诉你"**成没成功**"（bool）**和**"**结果是多少**"（数字）——
那就用 `return` 返回 bool，用 `out` 带出数字。

**`out` 的规则**：
- 定义时参数前加 `out`
- **调用时也要写 `out`**（可以顺便声明变量：`out int r`）
- **方法内部必须给 `out` 参数赋值**，否则编译错误
- 方法失败时，`out` 参数通常是默认值（数字是 0）

> **`ref` vs `out` 的区别**：
> | | `ref` | `out` |
> |---|---|---|
> | 传入前要初始化吗 | ✅ 要 | ❌ 不用 |
> | 方法内要赋值吗 | ❌ 不强制 | ✅ **必须** |
> | 用途 | 修改外部变量 | 额外带出一个值 |

## 六、元组：返回多个值（比 `out` 更现代）

`out` 只能解决"返回两个值"，但写起来啰嗦。**元组（tuple）更简洁**：

```csharp
static (int min, int max) GetMinMax(int[] numbers)
{
    int min = numbers[0];
    int max = numbers[0];
    foreach (int n in numbers)
    {
        if (n < min) min = n;
        if (n > max) max = n;
    }
    return (min, max);             // 返回一个"元组"
}

static void Main()
{
    var result = GetMinMax(new[] { 5, 2, 9, 1, 7 });
    Console.WriteLine($"最小 {result.min}，最大 {result.max}");

    // 也可以直接拆开
    var (lo, hi) = GetMinMax(new[] { 5, 2, 9, 1, 7 });
    Console.WriteLine($"最小 {lo}，最大 {hi}");
}
```

**语法拆解**：

```csharp
static (int min, int max) GetMinMax(...)
        └──────┬──────┘
        返回类型是一个元组：括号里写"类型 名字"，用逗号分隔

return (min, max);          // 用圆括号打包
var (lo, hi) = GetMinMax(); // 用 var + 括号拆包
```

> **Python 对照**：Python 的 `return a, b` 和 `a, b = func()`，C# 用元组做同样的事。
> 区别是 C# 需要**声明元组里每个值的类型和名字**。

**什么时候用元组，什么时候用 `out`？**

| 场景 | 用哪个 |
|---|---|
| 尝试型操作（成功/失败 + 结果） | `out`（这是 .NET 的惯例，如 `TryParse`） |
| 返回几个平级的计算值（最小/最大、宽/高） | **元组**（更清晰） |

## 七、方法重载 —— 同名不同参数

```csharp
static int Add(int a, int b) => a + b;
static double Add(double a, double b) => a + b;
static string Add(string a, string b) => a + b;
static int Add(int a, int b, int c) => a + b + c;
```

**四个方法都叫 `Add`，但参数不同，编译器会自动选对的那个**：

```csharp
Add(1, 2)              // 调用第 1 个 → 3
Add(1.5, 2.5)          // 调用第 2 个 → 4
Add("a", "b")          // 调用第 3 个 → ab
Add(1, 2, 3)           // 调用第 4 个 → 6
```

**重载的判定依据**（只看参数，**不看返回类型**）：

| 能重载吗 | 例子 |
|---|---|
| ✅ 参数**个数**不同 | `Add(int,int)` vs `Add(int,int,int)` |
| ✅ 参数**类型**不同 | `Add(int,int)` vs `Add(string,string)` |
| ❌ 只有**返回类型**不同 | `int Foo()` vs `string Foo()` → **编译错误** |
| ❌ 只有**参数名**不同 | `Foo(int a)` vs `Foo(int b)` → **编译错误** |

> **Python 对照**：Python 靠**默认参数**和 `*args` 解决同类问题，很少用重载。
> C# 的重载更常见，比如 `Console.WriteLine` 就有 18 个重载。
>
> **⚠️ 重要限制**：**Top-level 语句里的"本地函数"不支持重载**。
> 所以方法必须写在 `class` 里面才能重载 —— 这是 C# 要求"方法必须在类里"的一个实际原因。

## 八、可选参数和命名参数

### 可选参数：给参数一个默认值

```csharp
static string Greet(string name, string greeting = "你好")
{
    return $"{greeting}，{name}！";
}

Greet("小明")                  // 用默认值 → "你好，小明！"
Greet("小明", "早上好")         // 覆盖默认值 → "早上好，小明！"
```

**规则**：
- 有默认值的参数**必须放在参数列表最后**
- 默认值必须是**编译期常量**（不能是变量）

```csharp
static void Bad(string a = "x", string b) { }       // ❌ 编译错误：可选参数必须在最后
static void Good(string b, string a = "x") { }      // ✅
```

### 命名参数：调用时写参数名

```csharp
static void CreateUser(string name, int age, string city)
{
    Console.WriteLine($"{name}, {age}, {city}");
}

// 位置参数（按顺序）
CreateUser("小明", 20, "重庆");

// 命名参数（写名字，顺序随意）
CreateUser(age: 20, name: "小明", city: "重庆");
```

**命名参数的用处**：当参数很多、或含义不直观时，写名字能让代码**自解释**。

```csharp
// 看不出这两个 true/false 是什么意思
DrawBox(10, 20, true, false);

// 一目了然
DrawBox(width: 10, height: 20, fill: true, border: false);
```

## 九、表达式体方法 `=>`（简写）

如果方法体只有**一条语句**，可以这样简写：

```csharp
// 完整写法
static int Square(int x)
{
    return x * x;
}

// 表达式体写法（等价）
static int Square(int x) => x * x;
```

**再看几个例子**：

```csharp
static int Add(int a, int b) => a + b;
static string GetGreeting(string name) => $"你好，{name}";
static bool IsEven(int n) => n % 2 == 0;
static void PrintLine() => Console.WriteLine("----------");
```

> **`=>` 读作"goes to"，意思就是"这个方法的返回值是……"**
> 你在第 02 课的 switch 表达式里已经见过它了。

## 十、作用域（Scope）—— 变量在哪里能看见

```csharp
static void Main()
{
    int outer = 10;                // ← 在 Main 里声明

    if (outer > 5)
    {
        int inner = 20;            // ← 在 if 的 { } 里声明
        Console.WriteLine(outer);  // ✅ 能看见外面的
        Console.WriteLine(inner);  // ✅ 能看见自己这层的
    }

    Console.WriteLine(outer);      // ✅ 还在 Main 里
    // Console.WriteLine(inner);   // ❌ 编译错误：inner 的作用域已经结束
}
```

**规则**：
1. **变量只在它所在的那对 `{ }` 里有效**
2. 内层能看见外层，**外层看不见内层**
3. 出了 `{ }`，里面的变量就消失了

**方法之间的变量互相看不见**：

```csharp
static void MethodA()
{
    int x = 10;                    // 只属于 MethodA
}

static void MethodB()
{
    // Console.WriteLine(x);      // ❌ 编译错误：x 不存在
}
```

> **为什么要隔离？** 因为方法要能**独立测试和复用**。
> 如果方法能随便访问别的方法的变量，代码就变成一团乱麻。

**另一个作用域规则**：`for` 循环的 `i` 只在这个循环里有效：

```csharp
for (int i = 0; i < 5; i++) { }
// Console.WriteLine(i);          // ❌ 编译错误：i 只在循环里存在
```

## 十一、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `static int Add(int a, int b) { }` | 定义方法 | `def add(a, b):` | **必须写返回类型** |
| `void` | 不返回值 | 无返回 / `None` | 不需要 `return` |
| `return x;` | 返回值并结束方法 | `return x` | 所有分支都要有 |
| `static void F() => 表达式;` | 表达式体方法 | `lambda` 风格 | 只能有一条语句 |
| 值类型参数 | 传副本 | 类似 | 改参数不影响外面 |
| 数组/List 参数 | 传地址，改内容会影响外面 | 同 | **容易忘** |
| `string` 参数 | 引用类型但改不了 | 同 | **反直觉** |
| `ref int x` | 真引用，能改外部变量 | 无直接对应 | 调用时也要写 `ref` |
| `out int x` | 额外返回一个值 | 无直接对应 | 方法内必须赋值 |
| `(int a, int b)` | 元组返回多值 | `return a, b` | 要声明名字和类型 |
| `var (a, b) = F();` | 拆元组 | `a, b = f()` | — |
| 方法重载 | 同名不同参数 | 靠默认参数 | **不能只靠返回类型区分** |
| `string s = "x"` 默认值 | 可选参数 | `def f(a="x")` | 必须放最后 |
| `F(name: "x")` | 命名参数 | `f(name="x")` | — |
