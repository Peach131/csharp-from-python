## 一、`List<T>` 里的 `T` 是什么

你已经用了很多次：

```csharp
var nums = new List<int>();       // T 是 int
var names = new List<string>();   // T 是 string
var students = new List<Student>();  // T 是 Student
```

**`T` 是"类型参数"** —— 一个占位符，用的时候才填具体类型。

```csharp
List<T>          // 定义时：T 是占位符
List<int>        // 使用时：T 被替换成 int
```

> **为什么要这么设计？** 因为"列表"这个概念的逻辑和"装什么"无关。
> 如果不用泛型，要么给每种类型写一个 List（`IntList`、`StringList`...），
> 要么用 `object` 装一切（但会丢失类型信息、还要装箱）。

---

## 二、不用泛型的三种做法（都不好）

### 做法 1：每种类型写一个类

```csharp
class IntList { /* ... */ }
class StringList { /* ... */ }
class StudentList { /* ... */ }
// 无穷无尽，而且逻辑完全重复
```

### 做法 2：用 `object` 装一切（C# 1.0 的做法）

```csharp
class ObjectList
{
    private object[] _items = new object[10];
    public void Add(object item) { /* ... */ }
    public object Get(int index) => _items[index];
}

var list = new ObjectList();
list.Add(42);              // 装箱！42 被复制到堆上
list.Add("hello");
int x = (int)list.Get(0);  // 拆箱 + 强制转换，类型不安全
// int y = (int)list.Get(1);  // ❌ 运行时才炸 InvalidCastException
```

**问题**：
- **装箱/拆箱**：值类型每次读写都要堆分配
- **类型不安全**：`object` 可以装任何东西，写错了编译期发现不了
- **强制转换**：每次取值都要写 `(int)`

### 做法 3：泛型（正确答案）

```csharp
class MyList<T>
{
    private T[] _items = new T[10];
    private int _count;

    public void Add(T item)
    {
        _items[_count++] = item;
    }

    public T Get(int index) => _items[index];
}

var list = new MyList<int>();
list.Add(42);               // ✅ 不装箱
int x = list.Get(0);        // ✅ 不需要强制转换
// list.Add("hello");       // ❌ 编译错误！类型安全
```

**泛型同时解决了三个问题**：零装箱、类型安全、不用转换。

## 三、自己写一个泛型类

```csharp
class Box<T>                          // ★ 类名后面加 <T>
{
    private T _value;

    public Box(T value)               // 构造函数接收 T
    {
        _value = value;
    }

    public T GetValue()               // 返回 T
    {
        return _value;
    }

    public void SetValue(T value)     // 参数是 T
    {
        _value = value;
    }

    public override string ToString() => $"Box({_value})";
}
```

**使用**：

```csharp
var intBox = new Box<int>(42);            // ★ 尖括号里填具体类型
var strBox = new Box<string>("hello");
var studentBox = new Box<Student>(new Student());

Console.WriteLine(intBox.GetValue());      // 42
Console.WriteLine(strBox.GetValue());      // hello
```

> **`T` 只是惯例**。你也可以叫 `TItem`、`TKey`、`TValue`，多个类型参数就写 `<TKey, TValue>`。
> **惯例**：类型参数以 `T` 开头，用 PascalCase。

## 四、泛型方法

**类型参数也可以只用在方法上**：

```csharp
static T Max<T>(T a, T b) where T : IComparable<T>     // ★ 方法名后面加 <T>
{
    return a.CompareTo(b) > 0 ? a : b;
}
```

**调用时编译器自动推断类型**：

```csharp
Console.WriteLine(Max(3, 7));          // T 推断为 int
Console.WriteLine(Max(3.14, 2.71));    // T 推断为 double
Console.WriteLine(Max("abc", "xyz"));  // T 推断为 string（字符串可比较）
```

**也可以显式指定**：

```csharp
Max<int>(3, 7);
```

**更实用的例子：通用交换**

```csharp
static void Swap<T>(ref T a, ref T b)     // 第 04 课的 ref
{
    T temp = a;
    a = b;
    b = temp;
}

int x = 1, y = 2;
Swap(ref x, ref y);
Console.WriteLine($"{x}, {y}");          // 2, 1
```

## 五、泛型约束 `where`

**问题**：在泛型方法里，`T` 是未知类型，编译器不知道它有哪些成员。

```csharp
static T Max<T>(T a, T b)
{
    // return a.CompareTo(b) > 0 ? a : b;   // ❌ 编译错误：T 没有 CompareTo 方法
    // T 可能是任何类型，编译器不敢假设它有 CompareTo
}
```

**解决**：用 `where` **约束 T 必须满足什么条件**。

```csharp
static T Max<T>(T a, T b) where T : IComparable<T>     // ★ 约束：T 必须能比较
{
    return a.CompareTo(b) > 0 ? a : b;                 // ✅ 现在可以调 CompareTo 了
}
```

### 常用约束

| 约束 | 含义 | 用途 |
|---|---|---|
| `where T : class` | T 必须是**引用类型** | 允许 `T = null` |
| `where T : struct` | T 必须是**值类型** | 不允许 null |
| `where T : new()` | T 必须有**公开无参构造函数** | 可以 `new T()` |
| `where T : IComparable<T>` | T 必须实现某接口 | 可以调接口方法 |
| `where T : BaseClass` | T 必须继承某个类 | 可以调父类方法 |
| `where T : notnull` | T 不能为 null | 可空性检查 |
| `where T : unmanaged` | T 是非托管类型 | 高级场景 |

**可以组合**：

```csharp
static T Create<T>() where T : class, new()
{
    return new T();                   // 因为有 new() 约束，所以能 new
}
```

**约束的实际价值**：

```csharp
// 有 new() 约束 → 可以创建实例
static T CreateDefault<T>() where T : new() => new T();

// 有 struct 约束 → 可以拿到"零值"
static T GetDefault<T>() where T : struct => default;
```

## 六、⭐ 泛型为什么能做到"零装箱"（原理）

这是泛型**最大的性能价值**，也是第 11 课"装箱"的正面案例。

### 对比实验

```csharp
// ❌ 用 object（非泛型）：每次 Add 都装箱
var oldList = new ArrayList();
for (int i = 0; i < 1_000_000; i++) oldList.Add(i);

// ✅ 用泛型：完全不装箱
var newList = new List<int>(1_000_000);
for (int i = 0; i < 1_000_000; i++) newList.Add(i);
```

**实测**：`ArrayList` 会分配**几十 MB**、慢好几倍，`List<int>` 几乎不分配。

### 原理：C# 泛型是"运行时特化"

| 语言 | 泛型实现 | 值类型 | 性能 |
|---|---|---|---|
| **Java** | 类型擦除（编译后都是 `Object`） | 需要装箱 | 慢 |
| **Python** | 没有泛型（动态类型） | 运行时才知道 | 慢 |
| **C#** | **具现化（reified）** | **运行时特化** | **快** |

**C# 的两个关键机制**：

**① 值类型特化**：`List<int>` 和 `List<double>` 在运行时是**两份不同的原生代码**，
`int` 直接内联在数组里。

```csharp
Console.WriteLine(typeof(List<int>) == typeof(List<double>));    // False（不同类型）
```

**② 引用类型共享**：`List<string>` 和 `List<object>` 是不同类型，但 **JIT 内部共享同一份代码**
（因为引用都是 8 字节地址）。

```csharp
Console.WriteLine(typeof(List<string>) == typeof(List<object>)); // False（类型身份不同）
// 但 JIT 只生成了一份代码给它们共用
```

### ⚠️ 泛型类型的静态字段是独立的

```csharp
class Counter<T> { public static int Count; }

Counter<int>.Count = 1;
Counter<string>.Count = 2;

Console.WriteLine(Counter<int>.Count);      // 1  ← 不同的静态字段！
Console.WriteLine(Counter<string>.Count);   // 2
```

**每个"具体泛型类型"在运行时都是一个独立类型，有自己的静态字段。**

**实用技巧**：用这个特性能做"按类型自动缓存"，不需要 `Dictionary`：

```csharp
class Serializer<T>
{
    // 每种 T 自动获得一份独立的缓存
    private static readonly JsonSerializerOptions Options = new();
}
```

## 七、`default(T)` 和泛型的可空性

```csharp
static T GetDefault<T>() => default;      // 返回 T 的默认值

Console.WriteLine(GetDefault<int>());         // 0
Console.WriteLine(GetDefault<bool>());        // False
Console.WriteLine(GetDefault<string>() is null);  // True（引用类型默认是 null）
```

**`default(T)` 的含义**：

| T 是什么 | `default(T)` |
|---|---|
| 值类型 | 全 0 / false / 空字符 |
| 引用类型 | `null` |

> **回忆第 01 课你踩过的坑**：把 `SPoint` 从 `struct` 改成 `class` 后，
> `default(SPoint)` 从 `(0,0)` 变成了 `null` —— **这就是为什么 `SPoint?` 失去 `HasValue`。**

**C# 9+ 可以简化写法**：

```csharp
T value = default;              // 不用写 default(T)，编译器能推断
```

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `class Box<T> { }` | 泛型类 | `class Box(Generic[T])` | — |
| `static T Max<T>(...)` | 泛型方法 | `def max_(a: T, b: T) -> T` | — |
| `new Box<int>(42)` | 用具体类型 | `Box[int](42)` | — |
| `where T : class` | 约束为引用类型 | `T = TypeVar(bound=...)` | — |
| `where T : struct` | 约束为值类型 | — | — |
| `where T : new()` | 约束有无参构造函数 | — | — |
| `where T : IComparable<T>` | 约束实现接口 | — | — |
| `default` / `default(T)` | 该类型的默认值 | `None` / 0 | **值类型是 0，引用是 null** |
| `typeof(List<int>)` | 泛型的类型身份 | — | 不同 T 是不同类型 |
| `Counter<T>.Count` | 泛型静态字段 | — | **每种 T 各自独立** |
