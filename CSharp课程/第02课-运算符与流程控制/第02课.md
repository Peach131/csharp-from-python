## 二、算术运算符

### 基础四则运算

```csharp
int a = 10;
int b = 3;

Console.WriteLine(a + b);    // 13
Console.WriteLine(a - b);    // 7
Console.WriteLine(a * b);    // 30
Console.WriteLine(a / b);    // 3      ← 注意！不是 3.333
Console.WriteLine(a % b);    // 1      ← 余数
```

### ⚠️ 陷阱 1：整数除法会「砍掉」小数（和 Python 不同）

```csharp
int x = 7;
int y = 2;
Console.WriteLine(x / y);        // 3      ← 两个 int 相除，结果是 int
Console.WriteLine(7 / 2);        // 3
Console.WriteLine(7.0 / 2);      // 3.5    ← 有 double 参与，就是正常除法
Console.WriteLine(7 / 2.0);      // 3.5
Console.WriteLine(7m / 2);       // 3.5    ← decimal 也行
```

**为什么？** C# 规定：**两个 `int` 相除，结果还是 `int`**，小数部分直接被丢弃（不是四舍五入）。

**解决办法**：让其中一个变成小数类型。

```csharp
int total = 7;
int count = 2;

// ❌ 错误：结果是 3
double avg1 = total / count;

// ✅ 方法 1：显式转换其中一个
double avg2 = (double)total / count;      // 3.5

// ✅ 方法 2：乘以 1.0（不太好，但常见）
double avg3 = total * 1.0 / count;        // 3.5

// ✅ 方法 3：小数写在前面
double avg4 = total / (double)count;      // 3.5
```

> **Python 对照**：Python 的 `/` 永远是浮点除法（`7 / 2 = 3.5`），
> 要整数除法得写 `//`。
> **C# 正好反过来**：`/` 是整数除法（当两边都是 int），要浮点得自己转换。

### ⚠️ 陷阱 2：负数除法向「零」取整，Python 向「下」取整

```csharp
Console.WriteLine(-7 / 2);      // C#: -3     Python: -4
Console.WriteLine(-7 % 3);      // C#: -1     Python:  2
```

**C# 的规则**：除法结果**向零取整**（-3.5 → -3）；余数的**符号跟着被除数**（-7 是负数 → 余数是 -1）。

**Python 的规则**：除法结果**向下取整**（-3.5 → -4）；余数符号跟着除数。

> **这个差异平时不遇到，一旦遇到极难排查。** 记一句：
> **C# 的 `%` 结果符号跟左边那个数走。**

### 取余 `%` 的实用场景

```csharp
// 1. 判断奇偶
int n = 7;
if (n % 2 == 0) Console.WriteLine("偶数");
else            Console.WriteLine("奇数");

// 2. 判断能否整除
if (n % 3 == 0) Console.WriteLine("能被 3 整除");

// 3. 循环中的"每 N 次做一次"
for (int i = 1; i <= 10; i++)
{
    if (i % 3 == 0) Console.WriteLine($"{i} 是 3 的倍数");
}
```

### ⚠️ 陷阱 3：整数溢出

```csharp
int max = int.MaxValue;              // 2147483647
Console.WriteLine(max + 1);          // -2147483648   ← 溢出变成负数，【默认不报错】
```

C# **默认不检查**整数溢出。要让它报错，用 `checked`：

```csharp
try
{
    int result = checked(max + 1);   // 会抛 OverflowException
}
catch (OverflowException)
{
    Console.WriteLine("溢出了！");
}
```

> **Python 对照**：Python 的 `int` 是任意精度，**永远不会溢出**。
> C# 的 `int` 是固定 32 位，会。**这是 Python 程序员的必踩坑。**

## 三、赋值运算符（简写）

```csharp
int x = 10;

x += 5;      // 等价于 x = x + 5;     结果 15
x -= 3;      // 等价于 x = x - 3;     结果 12
x *= 2;      // 等价于 x = x * 2;     结果 24
x /= 4;      // 等价于 x = x / 4;     结果 6
x %= 4;      // 等价于 x = x % 4;     结果 2
```

### `++` 和 `--`（自增自减）

```csharp
int i = 5;
i++;          // i 变成 6     等价于 i = i + 1
i--;          // i 变成 5     等价于 i = i - 1
```

**⚠️ 注意前置和后置的区别**（考试常考，但实际代码里建议单独一行写，避免混淆）：

```csharp
int a = 5;
int b = a++;      // b = 5（先用旧值），然后 a 变成 6
Console.WriteLine($"a={a}, b={b}");    // a=6, b=5

int c = 5;
int d = ++c;      // c 先变成 6，然后 d = 6
Console.WriteLine($"c={c}, d={d}");    // c=6, d=6
```

> **建议**：**永远把 `++` 单独写一行**，不要嵌在表达式里。这样没有歧义，也没人会读错。

## 四、比较运算符 —— 结果是 `bool`

```csharp
int a = 10, b = 20;

Console.WriteLine(a == b);    // False   等于
Console.WriteLine(a != b);    // True    不等于
Console.WriteLine(a > b);     // False   大于
Console.WriteLine(a < b);     // True    小于
Console.WriteLine(a >= 10);   // True    大于等于
Console.WriteLine(a <= 10);   // True    小于等于
```

### ⚠️ 最容易犯的错：`=` 和 `==` 搞混

```csharp
int x = 10;         // = 是【赋值】：把 10 放进 x
if (x == 10)        // == 是【比较】：问"x 是不是等于 10"
{
    Console.WriteLine("相等");
}
```

**好消息**：C# 里写错会**编译错误**：

```csharp
// if (x = 10)      // ❌ 编译错误：无法将 int 隐式转换为 bool
```

> **Python 对照**：Python 里 `if x = 10` 是语法错误，这点两个语言一致。
> 但 C 语言里 `if (x = 10)` **能编译通过**（永远为真），这是经典的 bug 来源。
> C# 通过"条件必须是 bool"这条规则避免了它。

### `==` 用来比较字符串

```csharp
string s1 = "hello";
string s2 = "hello";

Console.WriteLine(s1 == s2);      // True    ← C# 的 == 对字符串是【按内容比较】
```

> ⚠️ 这一点很重要：C# 的 `string` 重载了 `==`，所以按内容比。
> 但**自定义的 class 用 `==` 是按地址比较**（不看内容），第 11 课会详细讲。

## 五、逻辑运算符

| 运算符 | 名称 | 作用 |
|---|---|---|
| `&&` | 逻辑与（AND） | 两边**都**为 true 才为 true |
| `\|\|` | 逻辑或（OR） | 有**一边**为 true 就为 true |
| `!` | 逻辑非（NOT） | 取反 |

```csharp
int age = 20;
bool hasTicket = true;

Console.WriteLine(age >= 18 && hasTicket);    // True    两个都满足
Console.WriteLine(age < 18 || hasTicket);     // True    满足一个
Console.WriteLine(!hasTicket);                // False   取反
```

**真值表**：

| A | B | `A && B` | `A \|\| B` | `!A` |
|---|---|---|---|---|
| true | true | **true** | true | false |
| true | false | false | **true** | false |
| false | true | false | **true** | true |
| false | false | false | false | true |

> **Python 对照**：`and` → `&&`，`or` → `||`，`not` → `!`。
> **C# 必须用符号，不能用单词。**

### ⭐ 短路求值（重要，能省性能还能防崩溃）

```csharp
string? name = null;

// ❌ 会崩溃：因为先算了 name.Length
// if (name.Length > 0 && name != null) { }

// ✅ 不会崩：&& 左边的 name != null 为 false，右边【根本不会执行】
if (name != null && name.Length > 0)
{
    Console.WriteLine(name);
}
```

**规则**：
- `&&`：**左边为 false 时，右边不执行**
- `||`：**左边为 true 时，右边不执行**

**这个特性非常有用**：把"可能出错的检查"放在前面，就能防止空引用崩溃。

> **Python 对照**：Python 的 `and` / `or` 也是短路的，行为一致。

## 六、`if` 语句

### 基本形式

```csharp
int score = 85;

if (score >= 90)
{
    Console.WriteLine("优秀");
}
else if (score >= 80)
{
    Console.WriteLine("良好");
}
else if (score >= 60)
{
    Console.WriteLine("及格");
}
else
{
    Console.WriteLine("不及格");
}
// 输出：良好
```

**语法要点**：
1. `if` 后面的条件**必须**用 `( )` 包起来
2. 条件的结果**必须是 `bool`**（不能像 C 语言那样用数字）
3. 代码块用 `{ }`，**即使只有一行也建议加**
4. `else if` 是连写的（不是 `elif`，也不是 `elseif`）

> **Python 对照**：Python 是 `elif`，C# 是 `else if`（两个词）。
> **C# 没有 `elif` 这个关键字。**

### 嵌套 `if` 的坏味道

```csharp
// ❌ 嵌套太深，难读
if (user != null)
{
    if (user.IsActive)
    {
        if (user.Age >= 18)
        {
            DoSomething();
        }
    }
}

// ✅ 用"卫语句"提前返回，扁平化
if (user == null) return;
if (!user.IsActive) return;
if (user.Age < 18) return;
DoSomething();          // 只在这一种情况下执行
```

> **这种"不满足就提前 return"的写法叫「卫语句」（guard clause）**，
> 你在第 01 课 TODO 6 里已经无意中用对了。

## 七、三元运算符 `? :`

如果 `if / else` 只是为了**给一个变量赋值**，可以缩写：

```csharp
int age = 20;

// 用 if / else（5 行）
string type1;
if (age >= 18)
{
    type1 = "成年";
}
else
{
    type1 = "未成年";
}

// 用三元运算符（1 行）
string type2 = age >= 18 ? "成年" : "未成年";
```

**语法结构**：

```
条件 ? 条件为真时的值 : 条件为假时的值
 │         │              │
 │         └─ 真分支       └─ 假分支
 └─ 必须是 bool
```

> **Python 对照**：Python 是 `"成年" if age >= 18 else "未成年"`（条件在中间），
> C# 是 `age >= 18 ? "成年" : "未成年"`（条件在最前）。
> **顺序完全不同，注意别写错。**

**建议**：只用于**简单的二选一赋值**。如果逻辑复杂，还是用 `if / else` 更清楚。

## 八、`switch` 语句

当你要对**同一个变量**做多个值的判断时，`switch` 比一串 `else if` 更清晰：

```csharp
int day = 3;

switch (day)
{
    case 1:
        Console.WriteLine("星期一");
        break;                        // ← 必须写！否则会"贯穿"到下一个 case
    case 2:
        Console.WriteLine("星期二");
        break;
    case 3:
        Console.WriteLine("星期三");
        break;
    default:                          // ← 都不匹配时执行（相当于 else）
        Console.WriteLine("其他");
        break;
}
// 输出：星期三
```

### ⚠️ `break` 不能忘

```csharp
switch (day)
{
    case 1:
        Console.WriteLine("星期一");
        // 忘了 break
    case 2:
        Console.WriteLine("星期二");    // ← 会连着执行！
        break;
}
```

**C# 的规定**：`case` 里**必须有** `break`（或 `return` / `throw` / `goto`），
**忘了会编译错误**——这一点比 C/C++ 安全（C/C++ 会默默贯穿）。

**想故意贯穿**（多个值走同一段代码）：

```csharp
switch (day)
{
    case 6:
    case 7:                           // ← 空的 case，会落到下面
        Console.WriteLine("周末");
        break;
    default:
        Console.WriteLine("工作日");
        break;
}
```

### `switch` 支持的类型

```csharp
switch (someValue)
{
    // 整数
    case 1: break;
    // 字符串
    case "apple": break;
    // 字符
    case 'A': break;
    // 枚举（第 08 课）
    // 模式匹配（如 case > 100，需要 C# 9+ 的 switch 表达式）
}
```

## 九、`switch` 表达式（C# 8+ 的现代写法，更好用）

如果你要的是"**根据值得到一个结果**"，用 `switch` 表达式比 `switch` 语句简洁得多：

```csharp
int score = 85;

string level = score switch
{
    >= 90 => "优秀",
    >= 80 => "良好",
    >= 60 => "及格",
    _     => "不及格"          // _ 是"其他所有情况"（相当于 default）
};

Console.WriteLine(level);      // 良好
```

**语法对比**：

| | `switch` 语句 | `switch` 表达式 |
|---|---|---|
| 写法 | `case X:` ... `break;` | `X => 值,` |
| 需要 `break` | ✅ 必须 | ❌ 不需要 |
| 能直接赋值 | ❌ | ✅ `var r = x switch {...}` |
| 适用场景 | 执行不同操作 | **根据值算出结果** |

**带条件的 `case`（模式匹配）**：

```csharp
int n = 7;
string desc = n switch
{
    0             => "零",
    < 0           => "负数",
    > 0 and < 10  => "个位数正数",      // and 组合条件
    _             => "大数"
};
Console.WriteLine(desc);      // 个位数正数
```

## 十、常用数学运算：`Math` 类

```csharp
Math.Abs(-5)             // 5          绝对值
Math.Max(3, 7)           // 7          较大值
Math.Min(3, 7)           // 3          较小值
Math.Round(3.567, 2)     // 3.57       四舍五入到 2 位小数
```

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `/` | 整数除法（两边都是 int 时） | `//` | **`7 / 2` = 3 不是 3.5** |
