## 一、先解决第 03 课留下的问题

第 03 课我们学过数组，但有个硬伤：

```csharp
int[] scores = new int[3];       // 长度固定是 3
scores[0] = 88;
scores[1] = 92;
scores[2] = 76;
// scores[3] = 81;               // ❌ IndexOutOfRangeException
```

**数组创建后不能变长。** 想加第 4 个元素？只能新建一个更大的数组，把数据搬过去：

```csharp
int[] bigger = new int[4];
for (int i = 0; i < scores.Length; i++) bigger[i] = scores[i];
bigger[3] = 81;
scores = bigger;                 // 麻烦得要命
```

**`List<T>` 就是为解决这个问题而生的** —— 它是**可变的动态数组**。

> **Python 对照**：**`List<T>` 才是 Python 的 `list`**！
> | Python | C# |
> |---|---|
> | `list`（可变长） | **`List<T>`** |
> | 固定长度的数组 | `int[]` |
>
> **第 03 课我说过"C# 数组 ≠ Python list"，现在答案来了：`List<T>` ≈ Python list。**

## 二、`List<T>` —— 最常用的集合

### 创建和使用

```csharp
// 创建
var numbers = new List<int>();                       // 空列表
var names = new List<string> { "张三", "李四" };      // 带初值
var fixed10 = new List<int>(10);                     // 预分配容量 10（优化用）

// 添加
numbers.Add(10);
numbers.Add(20);

// 访问
int first = numbers[0];              // 索引访问，和数组一样
int last = numbers[^1];              // 倒数第一个

// 修改
numbers[0] = 99;

// 删除
numbers.Remove(20);                  // 按【值】删除第一个匹配的
numbers.RemoveAt(0);                 // 按【索引】删除
numbers.Clear();                     // 清空

// 属性
int count = numbers.Count;           // ★ 元素个数（不是 Length！）
int capacity = numbers.Capacity;     // 已分配的容量

// 查询
bool has = numbers.Contains(10);     // 是否包含
int idx = numbers.IndexOf(20);       // 找索引，找不到返回 -1
```

### ⚠️ `Count` 还是 `Length`？

**这是初学者最容易搞混的一对**（第 03 课提过，这里再强调）：

| 类型 | 用哪个 | 例子 |
|---|---|---|
| 数组 `int[]` | **`.Length`** | `arr.Length` |
| 字符串 `string` | **`.Length`** | `"abc".Length` |
| **`List<T>`** | **`.Count`** | `list.Count` |
| `Dictionary` / `HashSet` | **`.Count`** | `dict.Count` |

> **记法**：**数组和字符串叫"长度"(Length)，集合叫"数量"(Count)。**

### 遍历

```csharp
var fruits = new List<string> { "苹果", "香蕉", "橘子" };

// foreach：只读，最简洁
foreach (string f in fruits)
{
    Console.WriteLine(f);
}

// for：需要索引或需要修改时
for (int i = 0; i < fruits.Count; i++)     // ★ 注意是 Count
{
    Console.WriteLine($"{i}: {fruits[i]}");
}
```

### `Add` vs `AddRange`

```csharp
var list = new List<int> { 1, 2 };
list.Add(3);                          // 加一个
list.AddRange(new[] { 4, 5, 6 });     // 加一批
// list 现在是 [1,2,3,4,5,6]
```

### 扩容机制（了解就好）

`List<T>` 内部**也是一个数组**。当元素超过容量时，它会：

1. 分配一个**两倍大小**的新数组
2. 把旧数据复制过去
3. 丢弃旧数组

```csharp
var list = new List<int>();     // Capacity = 0
list.Add(1);                    // 扩容到 4
list.Add(2); list.Add(3); list.Add(4);
list.Add(5);                    // 扩容到 8
Console.WriteLine($"Count = {list.Count}, Capacity = {list.Capacity}");
```

**实用建议**：如果**知道大概多少个元素**，用 `new List<T>(capacity)` 预分配，避免反复扩容：

```csharp
var result = new List<int>(1000);      // 一次分配好，不用扩容
for (int i = 0; i < 1000; i++) result.Add(i);
```

## 三、`Dictionary<K,V>` —— 键值对，O(1) 查找

### 问题：用 List 查找很慢

```csharp
var students = new List<Student>();
// ... 加了 1000 个学生

// 想按学号找一个人？只能遍历，最坏要找 1000 次
Student? found = null;
foreach (var s in students)
{
    if (s.Id == targetId) { found = s; break; }
}
```

**`Dictionary` 用"键"直接定位，一次就能找到**：

```csharp
var studentById = new Dictionary<int, Student>();
studentById[1001] = new Student { Name = "张三" };
Student s = studentById[1001];         // ★ 一次就拿到，不用遍历
```

> **Python 对照**：**`Dictionary<K,V>` = Python 的 `dict`**。
> ```python
> d = {"a": 1}
> d["a"]        # 取值
> ```
> ```csharp
> var d = new Dictionary<string, int> { ["a"] = 1 };
> d["a"]        // 取值
> ```

### 基本操作

```csharp
// 创建
var ages = new Dictionary<string, int>
{
    ["张三"] = 25,
    ["李四"] = 30
};

// 也可以用 Add
ages.Add("王五", 28);

// 读取
int age = ages["张三"];              // ⚠️ 键不存在会抛 KeyNotFoundException

// ★ 安全读取（推荐）
if (ages.TryGetValue("赵六", out int value))
{
    Console.WriteLine($"赵六的年龄是 {value}");
}
else
{
    Console.WriteLine("没有赵六这个人");
}

// 判断键是否存在
bool exists = ages.ContainsKey("张三");

// 修改
ages["张三"] = 26;                   // 键存在就覆盖
ages["赵六"] = 22;                   // 键不存在就新增

// 删除
ages.Remove("李四");

// 属性
int count = ages.Count;

// 遍历
foreach (KeyValuePair<string, int> kv in ages)
{
    Console.WriteLine($"{kv.Key} = {kv.Value}");
}

// 只遍历键 或 只遍历值
foreach (string name in ages.Keys) { }
foreach (int a in ages.Values) { }
```

### ⚠️ 两个必须记住的坑

**坑 1：用 `[]` 读不存在的键会抛异常**

```csharp
var d = new Dictionary<string, int>();
// int x = d["不存在"];              // ❌ KeyNotFoundException，程序崩溃

// ✅ 用 TryGetValue
if (d.TryGetValue("不存在", out int x)) { /* 用 x */ }
```

**这和 `int.Parse` vs `int.TryParse` 是同一个套路**（第 01 课学过）。

**坑 2：字典的"键"必须能当哈希键**

```csharp
var d = new Dictionary<string, int>();        // ✅ string 可以
var d2 = new Dictionary<int, string>();       // ✅ int 可以
var d3 = new Dictionary<Student, string>();   // ⚠️ 自定义类需要正确实现 GetHashCode 和 Equals
```

> **第 05 课讲过**：自定义 `class` 用 `==` 是按地址比较，而且默认的 `GetHashCode` 也基于地址。
> 所以**用自定义类当字典的键时，要么用 `record`（自动按值比较），要么自己重写 `Equals` 和 `GetHashCode`**。

### 实用示例：统计词频

**这是 `Dictionary` 最经典的用法**：

```csharp
string text = "apple banana apple cherry banana apple";
string[] words = text.Split(' ');

var counts = new Dictionary<string, int>();
foreach (string w in words)
{
    if (counts.TryGetValue(w, out int c))
    {
        counts[w] = c + 1;               // 已经有了，加 1
    }
    else
    {
        counts[w] = 1;                   // 第一次见到
    }
}

foreach (var kv in counts)
{
    Console.WriteLine($"{kv.Key}: {kv.Value} 次");
}
```

**输出**：
```
apple: 3 次
banana: 2 次
cherry: 1 次
```

## 四、`HashSet<T>` —— 自动去重

**需求**：统计"有多少个不重复的访客"。

用 List 要自己判断重复：

```csharp
var visitors = new List<string>();
if (!visitors.Contains(name))            // 每次都要遍历一遍，慢
{
    visitors.Add(name);
}
```

**`HashSet<T>` 自动去重**：

```csharp
var visitors = new HashSet<string>();
visitors.Add("张三");       // 加入成功，返回 true
visitors.Add("李四");       // 加入成功
visitors.Add("张三");       // ★ 已经存在，返回 false，不会重复加入

Console.WriteLine(visitors.Count);      // 2
```

**`Add` 的返回值**告诉你"这次到底加进去了没"：

```csharp
if (visitors.Add("张三"))
{
    Console.WriteLine("新访客");
}
else
{
    Console.WriteLine("老访客（已存在）");
}
```

### 集合运算（HashSet 的强项）

```csharp
var setA = new HashSet<int> { 1, 2, 3, 4 };
var setB = new HashSet<int> { 3, 4, 5, 6 };

// 交集：两个都有的
var intersection = new HashSet<int>(setA);
intersection.IntersectWith(setB);            // {3, 4}

// 并集：合并去重
var union = new HashSet<int>(setA);
union.UnionWith(setB);                       // {1,2,3,4,5,6}

// 差集：A 有但 B 没有的
var difference = new HashSet<int>(setA);
difference.ExceptWith(setB);                 // {1, 2}

// 判断子集
bool isSubset = new HashSet<int> { 1, 2 }.IsSubsetOf(setA);      // True
```

> **Python 对照**：`HashSet<T>` = Python 的 `set`，集合运算方法名不同但概念一致。
> Python `a & b` → C# `IntersectWith`；Python `a | b` → C# `UnionWith`；Python `a - b` → C# `ExceptWith`。

## 五、⭐ 三种集合怎么选

**这是本课最重要的表**：

| 需求 | 用什么 | 查找速度 | 有序吗 | 能重复吗 |
|---|---|---|---|---|
| **按顺序存一串，需要索引** | `List<T>` | O(n) | ✅ 保持插入顺序 | ✅ 能 |
| **按键快速查找** | `Dictionary<K,V>` | **O(1)** | ❌ 无序 | 键不能重复 |
| **去重 / 判断"在不在"** | `HashSet<T>` | **O(1)** | ❌ 无序 | ❌ 不能重复 |
| **长度固定的高性能场景** | `T[]` 数组 | O(n) | ✅ | ✅ |

### 决策流程

```
需要"键 → 值"的映射吗？
├─ 是 → Dictionary<K,V>
└─ 否 → 需要去重 / 频繁判断"是否存在"吗？
        ├─ 是 → HashSet<T>
        └─ 否 → List<T>          ← 默认选择
```

### 性能对照（实测数据）

在 **10 万个元素里查找 1000 次**（实测于本课示例代码）：

```
List.Contains        →   7.60 ms      O(n)
Dictionary.ContainsKey →  0.01 ms      O(1)
HashSet.Contains     →   0.01 ms      O(1)

→ List 比 Dictionary 慢了约 711 倍
```

> **差了 700 多倍。** 这就是"选对集合"的价值。
>
> **实用判断**：如果你发现自己写了一个 `foreach` 只为了"找某个东西在不在"，
> **那八成应该换成 `Dictionary` 或 `HashSet`**。
>
> （具体倍数会随数据量、CPU、Debug/Release 变化。数据量越大，差距越夸张：
> 100 万个元素时，List 的查找成本还要再涨 10 倍，而 Dictionary 几乎不变。）

## 六、集合初始化器和一些小技巧

```csharp
// List
var list = new List<int> { 1, 2, 3 };

// Dictionary：两种写法
var d1 = new Dictionary<string, int>
{
    { "a", 1 },              // 写法 1
    { "b", 2 }
};
var d2 = new Dictionary<string, int>
{
    ["a"] = 1,               // 写法 2（更简洁，推荐）
    ["b"] = 2
};

// HashSet
var set = new HashSet<string> { "a", "b" };
```

### 数组和 List 互转

```csharp
int[] arr = { 1, 2, 3 };
List<int> list = arr.ToList();           // 数组 → List
int[] back = list.ToArray();             // List → 数组

// 需要 using System.Linq;
```

### 一行输出 List 的内容

```csharp
var list = new List<int> { 1, 2, 3 };
Console.WriteLine(string.Join(", ", list));      // 1, 2, 3
```

> 这个方法在第 03 课输出数组时用过，`List` 也一样能用。

## 七、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `new List<int>()` | 可变数组 | `[]` | 元素个数用 `.Count` |
| `list.Add(x)` | 添加 | `list.append(x)` | — |
| `list.AddRange(xs)` | 批量添加 | `list.extend(xs)` | — |
| `list.Remove(x)` | 按值删除 | `list.remove(x)` | 删第一个匹配的 |
| `list.RemoveAt(i)` | 按索引删 | `del list[i]` | — |
| `list[0]` / `list[^1]` | 索引访问 | `list[0]` / `list[-1]` | — |
| `list.Count` | 元素个数 | `len(list)` | **不是 Length** |
| `new List<int>(100)` | 预分配容量 | — | 避免反复扩容 |
| `new Dictionary<K,V>()` | 键值对 | `{}` | — |
| `dict[key] = v` | 增/改 | `d[k] = v` | **读不存在的键会抛异常** |
| `dict.TryGetValue(k, out v)` | 安全读 | `d.get(k)` | **推荐用这个** |
| `dict.ContainsKey(k)` | 判断键存在 | `k in d` | — |
| `foreach (var kv in dict)` | 遍历 | `for k, v in d.items()` | kv.Key / kv.Value |
| `new HashSet<T>()` | 去重集合 | `set()` | — |
| `set.Add(x)` | 添加（返回是否新增） | `set.add(x)` | 返回 bool |
| `IntersectWith` / `UnionWith` / `ExceptWith` | 交/并/差集 | `&` / `\|` / `-` | 原地修改 |
