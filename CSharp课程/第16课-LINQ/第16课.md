## 一、先看 LINQ 解决了什么

**第 09 课你是这么写筛选的**：

```csharp
var result = new List<int>();
foreach (int n in nums)
{
    if (n % 2 == 0) result.Add(n);
}
```

**用了第 14 课的委托**，可以写成通用方法：

```csharp
var result = Filter(nums, n => n % 2 == 0);
```

**用 LINQ，一行搞定**：

```csharp
var result = nums.Where(n => n % 2 == 0).ToList();
```

**LINQ（Language Integrated Query，语言集成查询）= 一组内置的集合处理方法。**

> **Python 对照**：LINQ ≈ 列表推导 + `filter`/`map`/`sorted` + `itertools` 的合体，
> 但**功能更强、名字更统一**。
> ```python
> result = [n for n in nums if n % 2 == 0]
> ```
> ```csharp
> var result = nums.Where(n => n % 2 == 0).ToList();
> ```

**用 LINQ 的前提**：文件顶部要有

```csharp
using System.Linq;
```

（很多项目配置为自动引入，见 `.csproj` 的 `<ImplicitUsings>`）

## 二、最常用的 10 个方法

假设有数据：

```csharp
record Student(string Name, int Grade, string City);

var students = new List<Student>
{
    new("张三", 88, "重庆"),
    new("李四", 92, "成都"),
    new("王五", 76, "重庆"),
    new("赵六", 95, "北京"),
    new("钱七", 55, "成都")
};
```

### 1. `Where` —— 筛选（相当于 Python 的 `filter` / 列表推导的 if）

```csharp
var passed = students.Where(s => s.Grade >= 60).ToList();
```

### 2. `Select` —— 转换/投影（相当于 `map`）

```csharp
var names = students.Select(s => s.Name).ToList();
var doubled = students.Select(s => s.Grade * 2).ToList();

// 投影成匿名对象（临时组合几个字段）
var brief = students.Select(s => new { s.Name, s.Grade }).ToList();
```

### 3. `OrderBy` / `OrderByDescending` —— 排序

```csharp
var byGrade = students.OrderBy(s => s.Grade).ToList();             // 升序
var byGradeDesc = students.OrderByDescending(s => s.Grade).ToList(); // 降序

// 多级排序
var multi = students.OrderBy(s => s.City).ThenByDescending(s => s.Grade).ToList();
```

### 4. `First` / `FirstOrDefault` —— 取第一个

```csharp
var first = students.First(s => s.Grade >= 90);              // 找不到会抛异常
var safe = students.FirstOrDefault(s => s.Grade >= 100);     // 找不到返回 null（或默认值）
```

**⚠️ 这两个的区别很重要**：

| 方法 | 找不到时 |
|---|---|
| `First(predicate)` | **抛 `InvalidOperationException`** |
| `FirstOrDefault(predicate)` | 返回 `null`（引用类型）/ `default`（值类型） |

**推荐用 `FirstOrDefault`**，除非你确定一定有。

### 5. `Any` / `All` —— 存在性判断

```csharp
bool hasExcellent = students.Any(s => s.Grade >= 90);     // 有任何一个满足吗
bool allPassed = students.All(s => s.Grade >= 60);        // 全部都满足吗
bool isEmpty = !students.Any();                            // 列表是空的吗（比 Count == 0 快）
```

### 6. `Count` / `Sum` / `Average` / `Max` / `Min`

```csharp
int count = students.Count();                      // 元素个数
int countPassed = students.Count(s => s.Grade >= 60);  // 满足条件的个数
int total = students.Sum(s => s.Grade);            // 求和
double avg = students.Average(s => s.Grade);       // 平均
int max = students.Max(s => s.Grade);              // 最大
int min = students.Min(s => s.Grade);              // 最小
```

### 7. `GroupBy` —— 分组

```csharp
var byCity = students.GroupBy(s => s.City);

foreach (var group in byCity)
{
    Console.WriteLine($"{group.Key}：{group.Count()} 人，平均 {group.Average(s => s.Grade):F1} 分");
}
```

**输出**：
```
重庆：2 人，平均 82.0 分
成都：2 人，平均 73.5 分
北京：1 人，平均 95.0 分
```

### 8. `Distinct` / `Take` / `Skip`

```csharp
var cities = students.Select(s => s.City).Distinct().ToList();   // 去重
var top2 = students.OrderByDescending(s => s.Grade).Take(2).ToList();   // 前 2 个
var rest = students.OrderByDescending(s => s.Grade).Skip(2).ToList();   // 跳过前 2 个
```

### 9. `Join` —— 连接两个集合

```csharp
var classes = new List<(string City, string Province)>
{
    ("重庆", "重庆市"), ("成都", "四川省"), ("北京", "北京市")
};

var joined = students.Join(
    classes,
    s => s.City,              // 左边用什么做键
    c => c.City,              // 右边用什么做键
    (s, c) => new { s.Name, c.Province }   // 结果怎么组合
);

foreach (var item in joined)
    Console.WriteLine($"{item.Name} - {item.Province}");
```

### 10. `ToList` / `ToArray` / `ToDictionary`

```csharp
var list = query.ToList();                                  // 变成 List<T>
var array = query.ToArray();                                // 变成数组
var dict = students.ToDictionary(s => s.Name, s => s.Grade);  // 变成 Dictionary
```

## 三、⚠️⚠️ 最大的坑：延迟执行（Deferred Execution）

**这是 LINQ 最重要的概念，也是最容易出错的地方。**

```csharp
var nums = new List<int> { 1, 2, 3, 4, 5 };

var query = nums.Where(n => n > 2);       // ← 此时【什么都没算】！

nums.Add(100);                            // 改动会反映到 query 里

foreach (int n in query)                  // ← 真正执行发生在【这一刻】
{
    Console.Write($"{n} ");               // 输出：3 4 5 100
}
```

**`Where` 只是"记录了一个查询意图"，真正执行发生在遍历时。**

### 为什么会这样？

`Where` 返回的是 `IEnumerable<T>`，**不是 `List<T>`**。
它内部是一个"迭代器"，只有你开始遍历（`foreach`）或调用
`ToList()` / `Count()` / 聚合方法时，才会真正去跑。

### 三个必知的后果

**后果 1：数据变了，查询结果也会变**

```csharp
var q = nums.Where(n => n > 2);
nums.Add(100);
Console.WriteLine(q.Count());      // 包含了新加的 100
```

**后果 2：可能重复计算**

```csharp
var q = nums.Where(n =>
{
    Console.WriteLine($"  正在检查 {n}");     // 每次遍历都会打印！
    return n > 2;
});

Console.WriteLine($"第一次 Count：{q.Count()}");    // 执行一遍
Console.WriteLine($"第二次 Count：{q.Count()}");    // 又执行一遍！
```

**后果 3：可能出现"集合被修改"异常**

```csharp
var q = nums.Where(n => n > 2);
foreach (int n in q)
{
    nums.Add(999);        // ❌ InvalidOperationException：集合被修改了
}
```

### ✅ 解决：需要固定结果就用 `ToList()`

```csharp
var list = nums.Where(n => n > 2).ToList();      // ★ 立即执行，结果固定

nums.Add(100);
Console.WriteLine(list.Count);                    // 不受影响
```

**规则**：

| 情况 | 做法 |
|---|---|
| 结果要**多次使用** | **`.ToList()`**（立即执行，固定下来） |
| 只**遍历一次** | 保持 `IEnumerable` 也可以（省一次内存分配） |
| 数据在遍历期间**可能变化** | **必须 `.ToList()`** |

> **实用建议（初学者）**：**养成习惯，查询完就 `.ToList()`。**
> 这样行为最直观，也避免所有延迟执行的坑。等熟练了再按需优化。

## 四、方法语法 vs 查询语法

LINQ 有**两种写法**，功能完全等价：

```csharp
// ① 方法语法（链式调用，最常用）
var result1 = students
    .Where(s => s.Grade >= 60)
    .OrderByDescending(s => s.Grade)
    .Select(s => s.Name)
    .ToList();

// ② 查询语法（像 SQL，适合多表连接）
var result2 = (from s in students
               where s.Grade >= 60
               orderby s.Grade descending
               select s.Name).ToList();
```

**怎么选？**

| 情况 | 推荐 |
|---|---|
| 简单筛选/转换/排序 | **方法语法**（更短） |
| 多集合 Join | 查询语法可能更清楚 |
| **不确定** | **方法语法**（更通用，能表达所有操作） |

> **实际项目中方法语法占绝大多数**。本课主要用方法语法。

## 五、链式调用的威力

**LINQ 最爽的地方是"链式组合"** —— 每一步的输出是下一步的输入。

**需求**：找出成都学生里成绩 ≥ 70 的，按成绩降序，取前 2 名，只要名字。

```csharp
var result = students
    .Where(s => s.City == "成都")            // 1. 筛城市
    .Where(s => s.Grade >= 70)               // 2. 筛成绩
    .OrderByDescending(s => s.Grade)         // 3. 排序
    .Take(2)                                  // 4. 取前 2
    .Select(s => s.Name)                      // 5. 只要名字
    .ToList();                                // 6. 固定结果
```

**用传统循环要写多少行？** 大概 15-20 行，而且要新建临时集合。
**LINQ 只要 6 行，而且每一步的意图都写在名字里。**

## 六、⚠️ LINQ 的性能代价（要知道）

**LINQ 不是免费的**：

| 代价 | 说明 |
|---|---|
| **委托调用开销** | 每个元素都要调用一次 Lambda（比内联循环慢） |
| **迭代器分配** | 每次 `Where`/`Select` 都会创建一个迭代器对象 |
| **可能多次遍历** | 忘了 `ToList()` 时，链式查询可能重复计算 |
| **闭包分配** | Lambda 捕获变量时（第 14 课）每次分配 |

**实用建议**：

| 场景 | 用什么 |
|---|---|
| **业务逻辑、数据处理**（执行次数少） | **LINQ**（可读性 >> 微性能） |
| **热路径**（每秒执行几万次，比如 Unity 的 `Update`） | **手写循环** |
| 数据量极大（百万级）且性能敏感 | 手写循环，或测量后再决定 |

> **默认用 LINQ。** 只有**测量证明**它是瓶颈时才换成循环。
> **"能测量就不要猜"** —— 不要凭感觉优化。

## 七、本课新语法速查表

| LINQ 方法 | 作用 | Python 对照 |
|---|---|---|
| `Where(pred)` | 筛选 | `filter` / 列表推导 if |
| `Select(f)` | 转换/投影 | `map` / 列表推导 |
| `OrderBy` / `OrderByDescending` | 排序 | `sorted(key=)` |
| `ThenBy` / `ThenByDescending` | 多级排序 | `sorted(key=(a,b))` |
| `First` / `FirstOrDefault` | 取第一个 | `next(iter)` |
| `Any` / `All` | 存在 / 全部满足 | `any` / `all` |
| `Count` / `Sum` / `Average` / `Max` / `Min` | 聚合 | `len` / `sum` / `statistics.mean` / `max` / `min` |
| `GroupBy` | 分组 | `itertools.groupby` |
| `Distinct` | 去重 | `set()` |
| `Take` / `Skip` | 取前 N / 跳过 N | 切片 |
| `Join` | 连接两个集合 | 手动或 pandas merge |
| `ToList` / `ToArray` / `ToDictionary` | 转成具体集合 | `list()` / `dict()` |
| `Where(...).ToList()` | **立即执行（防延迟执行坑）** | — |
