## 一、问题：想让方法"可替换"

**需求**：一个筛选方法，条件由调用者决定。

**不用委托的笨办法**：为每种条件写一个方法。

```csharp
static List<int> FilterEven(List<int> nums)     // 筛偶数
{
    var result = new List<int>();
    foreach (int n in nums) if (n % 2 == 0) result.Add(n);
    return result;
}

static List<int> FilterGreaterThan10(List<int> nums)   // 筛大于 10
{
    var result = new List<int>();
    foreach (int n in nums) if (n > 10) result.Add(n);
    return result;
}
// 加新条件就要加新方法……无穷无尽
```

**问题**：`foreach` 那段逻辑**完全一样**，只有 `if` 的条件不同。

**能不能把"条件"当成参数传进来？** 能 —— **这就是委托**。

## 二、委托是什么

> **委托（delegate）= 一个"能装方法"的变量。**

普通变量装数据：

```csharp
int x = 42;              // x 装了一个数字
```

委托变量装方法：

```csharp
Func<int, bool> isEven = IsEvenNumber;    // isEven 装了一个方法
```

**`Func<int, bool>` 的含义**：

```
Func< int ,  bool >
      └─┬─┘   └─┬──┘
     参数类型   返回类型
```

**读作**："一个方法，接收 `int`，返回 `bool`"。

### 现在筛选方法可以通用

```csharp
// 条件由参数传入 —— 一个方法处理所有情况
static List<int> Filter(List<int> nums, Func<int, bool> condition)
{
    var result = new List<int>();
    foreach (int n in nums)
    {
        if (condition(n))            // ★ 调用传进来的方法
        {
            result.Add(n);
        }
    }
    return result;
}

// 用的时候传入不同的条件
var evens = Filter(nums, n => n % 2 == 0);
var bigs = Filter(nums, n => n > 10);
var odds = Filter(nums, n => n % 2 != 0);
```

**一个新条件，只写一个表达式，不用改 `Filter`。**

> **Python 对照**：Python 直接把函数当参数传，不需要特殊类型。
> ```python
> def filter_list(nums, condition):
>     return [n for n in nums if condition(n)]
> ```
> C# 必须声明**方法签名**（`Func<int, bool>`）—— 这是静态类型语言的代价，
> 好处是**编译器能检查你传的方法签名对不对**。

## 三、三种内置委托（覆盖 99% 场景）

C# 预定义了常用的委托类型，**你几乎不需要自己定义 `delegate`**。

| 类型 | 含义 | 例子 |
|---|---|---|
| **`Action`** | 无参数、无返回值 | `Action a = () => Console.WriteLine("hi");` |
| **`Action<T>`** | 有参数、无返回值 | `Action<string> log = msg => Console.WriteLine(msg);` |
| **`Action<T1,T2>`** | 两个参数、无返回值 | `Action<string,int> f = (s,i) => { };` |
| **`Func<TResult>`** | 无参数、**有返回值** | `Func<int> getRandom = () => 42;` |
| **`Func<T,TResult>`** | 一个参数、有返回值 | `Func<int,bool> isEven = n => n % 2 == 0;` |
| **`Func<T1,T2,TResult>`** | 两个参数、有返回值 | `Func<int,int,int> add = (a,b) => a + b;` |
| **`Predicate<T>`** | 一个参数、返回 `bool`（判断用） | `Predicate<int> p = n => n > 5;` |

**记忆方法**：

```
Action  → 有去无回（可以有参数，但没有返回值）
Func    → 最后一格是返回类型，前面都是参数

Func<int, string, bool>
     └┬─┘  └──┬─┘  └─┬┘
    参数1   参数2   返回
```

> **`Func` 最多支持 16 个参数**（够用了）。

### 什么时候用哪个

| 场景 | 用 |
|---|---|
| 执行一个动作（打印、写日志、更新状态） | **`Action`** |
| 算一个值返回 | **`Func`** |
| 判断 true/false（筛选条件） | **`Predicate`** 或 `Func<T,bool>` |

## 四、Lambda 表达式 —— 匿名方法的简写

**命名方法**（要先定义一个方法）：

```csharp
static bool IsEven(int n) => n % 2 == 0;
Func<int, bool> f = IsEven;
```

**Lambda**（直接写，不用起名字）：

```csharp
Func<int, bool> f = n => n % 2 == 0;
//                   └┬┘   └────┬────┘
//                  参数    方法体（表达式）
```

**`=>` 读作 "goes to"，意思是"接收这些参数，返回这个结果"。**

### 三种写法

```csharp
// ① 单参数、单表达式（最简洁）
Func<int, int> square = x => x * x;

// ② 多参数
Func<int, int, int> add = (a, b) => a + b;

// ③ 多语句（用 { } 包起来，需要 return）
Func<int, string> describe = n =>
{
    if (n > 0) return "正数";
    if (n < 0) return "负数";
    return "零";
};

// ④ 无参数
Action hello = () => Console.WriteLine("hi");
```

> **Python 对照**：
> ```python
> square = lambda x: x * x
> add = lambda a, b: a + b
> ```
> Python 的 `lambda` 只能写**单个表达式**；C# 的 Lambda 可以写**多语句块**，更强大。

### 快速判断 Lambda 的参数类型

**常见错误**：忘记写参数类型会不会报错？

```csharp
Func<int, bool> f = n => n > 5;          // ✅ 编译器能推断 n 是 int
// var g = n => n > 5;                   // ❌ 编译错误：无法推断类型
```

**规则**：**赋值给有明确类型的委托变量时，参数类型可以省略**。

## 五、闭包 —— Lambda 捕获外部变量

```csharp
int threshold = 10;
Func<int, bool> isBig = n => n > threshold;      // ★ 捕获了 threshold
```

**Lambda 里用了外部的 `threshold`** —— 这叫**闭包（closure）**。

### ⚠️ 闭包会分配对象（性能点）

**编译器会偷偷生成一个类来"装"被捕获的变量**：

```csharp
// 你写的代码
int threshold = 10;
Func<int, bool> f = n => n > threshold;

// 编译器实际生成的（概念上）
class DisplayClass { public int threshold; public bool Method(int n) => n > threshold; }
var dc = new DisplayClass { threshold = 10 };
Func<int, bool> f = dc.Method;
```

**后果**：**每次创建这个 Lambda，都会堆分配一个对象**。

**规则**：

| Lambda | 分配吗 |
|---|---|
| 捕获了外部变量（闭包） | ✅ **每次分配** |
| 没捕获任何变量 | ❌ C# 9+ 会缓存成静态单例，**零分配** |

```csharp
// ❌ 每次循环都分配一个闭包对象
foreach (var item in list)
{
    Process(x => x > item);        // 捕获了 item
}

// ✅ 提取成不捕获的静态方法/Lambda
static bool IsPositive(int x) => x > 0;
foreach (var item in list)
{
    Process(IsPositive);            // 不捕获，可缓存
}
```

> **Unity 里这条极其重要**：`Update()` 每帧创建闭包 = 每帧产生垃圾 = GC 卡顿。

### 经典陷阱：循环变量捕获

```csharp
var actions = new List<Action>();

// foreach：C# 5 之后每次迭代是新变量 → 安全
foreach (var i in Enumerable.Range(0, 3))
    actions.Add(() => Console.Write($"{i} "));
foreach (var a in actions) a();          // 输出：0 1 2  ✅

// for：循环变量只有一个 → 全部捕获同一个
actions.Clear();
for (int i = 0; i < 3; i++)
    actions.Add(() => Console.Write($"{i} "));
foreach (var a in actions) a();          // 输出：3 3 3  ❌

// 修复：在循环体内创建局部副本
actions.Clear();
for (int i = 0; i < 3; i++)
{
    int copy = i;
    actions.Add(() => Console.Write($"{copy} "));
}
foreach (var a in actions) a();          // 输出：0 1 2  ✅
```

> **Python 里也有同样的坑**：`[lambda: i for i in range(3)]` 全部返回 2。

## 六、`event` —— 委托的特殊用法（了解）

**事件 = 受限制的委托**：外面只能 `+=` 订阅 / `-=` 取消，不能直接赋值或触发。

```csharp
class Button
{
    // 声明事件：外面只能 += / -=
    public event Action? Clicked;

    public void Click()
    {
        Clicked?.Invoke();          // ★ 只有类内部能触发（?. 防止没人订阅时崩溃）
    }
}

// 使用
var btn = new Button();
btn.Clicked += () => Console.WriteLine("处理点击 1");
btn.Clicked += () => Console.WriteLine("处理点击 2");
btn.Click();                        // 输出两行
```

**为什么要用 `event` 而不是 `public Action Clicked;`？**
因为如果只是公开字段，外面可以 `btn.Clicked = null;` 把别人的订阅全清掉 —— **破坏封装**。

> **本课只需"看懂"事件**。Unity 的 UI 事件、WPF 的按钮点击都是这个机制。

## 七、本课新语法速查表

| 语法 | 作用 | Python 对照 | 易错点 |
|---|---|---|---|
| `Func<int,bool>` | 有返回值的方法类型 | 无（直接传函数） | **最后一格是返回类型** |
| `Action<T>` | 无返回值的方法类型 | 无 | — |
| `Predicate<T>` | 返回 bool 的委托 | 无 | — |
| `x => x * 2` | Lambda 表达式 | `lambda x: x*2` | — |
| `(a, b) => a + b` | 多参数 Lambda | `lambda a,b: a+b` | — |
| `x => { ... return y; }` | 多语句 Lambda | 不支持 | 要写 `return` |
| 闭包 | Lambda 捕获外部变量 | 同 | **会堆分配** |
| `for` 捕获循环变量 | — | 同 | **必须用局部副本** |
| `event Action X;` | 事件 | 无 | 外面只能 `+=` / `-=` |
| `X?.Invoke()` | 安全触发事件 | — | 防止无订阅者时崩溃 |
