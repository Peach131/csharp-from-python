# 从 Python 到 C# —— 一套"能跑起来"的 C# 入门课程

> 写给**有其他语言基础、但对 C# 完全陌生**的人。
> 每节课都有：**原理讲解 + 可运行的示例 + 留给你动手的练习**。
> 全部代码都验证过：**编译 0 警告 0 错误，示例逐课实跑通过**。

---

## 这套课有什么不同

| 特点 | 说明 |
|---|---|
| **一课一个独立解决方案** | 打开某一课的 `.sln`，就只编译那一课。互不干扰，不用改任何配置 |
| **每节课都有"痛点驱动"** | 先给你看"不用这个特性会多痛"，再引出新知识 |
| **大量 `Python 对照`** | 每个新概念都标注 Python 里的对应物和**关键差异** |
| **示例逐行中文注释** | 不是"能跑就行"，是"每一行都告诉你为什么这么写" |
| **数据来自实测** | 性能对比、内存占用、编译行为都是**跑出来的真实数字**，不是抄的 |

## 快速开始

### 环境要求

- **.NET SDK 9.0 或以上**（[下载](https://dotnet.microsoft.com/download)）
- 任意 C# IDE：**JetBrains Rider**（推荐）或 **Visual Studio 2022**
- 命令行验证：`dotnet --version` 能输出版本号即可

### 学一节课的标准流程

以第 04 课为例：

```bash
# 1. 打开这一课的解决方案（Rider：File → Open → 选 .sln）
#    命令行也可以直接跑：
cd 第04课-方法与参数
dotnet run --project Lesson04Demo        # 先跑示例，看效果
dotnet run --project Lesson04Practice    # 再做练习
```

**四步走**：

1. **读课文** —— `第NN课-xxx/第NN课.md`
   （原理 → 语法 → 逐行解释 → 验收自测题）
2. **跑示例** —— `LessonNNDemo`，逐行读 `Program.cs` 里的中文注释，对照输出
3. **做练习** —— `LessonNNPractice`，按文件里的 `TODO` 一步步写，每个 TODO 都有预期输出
4. **做自测** —— 课文末尾的验收题，能答上大部分就算过关

## 给正在学的人：几个省时间的提示

**1. 每课一个独立解决方案，别在一个项目里堆所有练习**

`第NN课.sln` 里只有那一课的两个项目。想复习旧课，直接打开那一课的 `.sln`。

**2. 改代码前先停掉正在运行的程序**

否则会报文件被锁：

```
error MSB3027: 无法将 ... 复制到 ...，文件被 ".NET Host" 锁定
```

**解法**：按 `Ctrl + F2` 停止运行，或者去任务管理器结束 `dotnet` 进程。
**不用重装 SDK、不用删 obj、不用重启电脑。**

**3. 看到黄色警告不要忽略**

课程里反复出现的一个主题是：**警告是编译器在预言 bug**。
比如 `CS8618`（字段可能为 null）如果不处理，将来就是 `NullReferenceException`。

**4. 卡住的地方，先做实验再问人**

这套课里几乎每个结论都有对应的实测数据。如果你对某个结论存疑，
**自己写个实验验证它** —— 这比读十遍文档都有用。
